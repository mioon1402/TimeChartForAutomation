# TimeChart Studio — 자동화 설비 타임차트 설계 도구

PLC 프로그램을 불러와 **스캔 시뮬레이션으로 타임차트를 자동 생성**하고, 마우스로 다듬은 뒤
**표제란이 있는 보고서(PDF)** 로 출력하는 자동화 설비 전용 타임차트 도구입니다.

- 설치 필요 없음: `release/TimeChartStudio.html` 파일 하나를 더블클릭하면 브라우저(Chrome/Edge)에서 실행됩니다.
- 인터넷 연결 없이 동작하며, 작업 내용은 브라우저에 자동 백업됩니다. 데이터가 외부로 전송되지 않습니다.
- 한국어 / English UI, 라이트 / 다크 테마.

## 빠른 시작

1. `release/TimeChartStudio.html`을 PC로 복사해 더블클릭합니다. USB나 사내망 PC에서도 동작합니다.
2. 처음에는 **드릴 가공 유닛** 예제 차트가 열립니다. 상단 메뉴 `파일 → 템플릿`에서 로봇 핸드셰이크, 인버터 컨베이어 예제도 열 수 있습니다.
3. **PLC 시뮬레이션** 탭에서 `예제 불러오기…` → 미쓰비시 / LS / 지멘스 / ST 예제를 고른 뒤
   `▶ 시뮬레이션 → 타임차트 생성`을 누르면 PLC 프로그램으로부터 차트가 만들어집니다.
4. **보고서** 탭에서 `인쇄 / PDF 저장`을 누르고 인쇄 대화상자에서 "PDF로 저장"을 선택합니다. `Ctrl+P`로도 됩니다.

## 주요 기능

### 1. PLC 프로그램 → 타임차트 자동 생성
| 지원 언어 | 형식 |
|---|---|
| 미쓰비시 GX Works2/3, GX Developer | 니모닉 텍스트, **GX Works CSV/TSV 내보내기 파일** (UTF-8/UTF-16/EUC-KR 자동 인식) |
| LS ELECTRIC XG5000 (XGK/XGB) | 니모닉 (LOAD, AND NOT, AND LOAD, MPUSH …) |
| 지멘스 STEP7 / TIA Portal | STL(AWL), 영문·독일어 니모닉 (A/U, O, A( … ), =, S/R, FP/FN, L/T, S5 타이머, 카운터, 점프) |
| IEC 61131-3 ST | CODESYS, TwinCAT, SCL, XG5000 ST, GX Works3 ST (IF/CASE/FOR/WHILE, TON/TOF/TP, R_TRIG, CTU/CTD, AT 주소) |

- 스캔 사이클 시뮬레이션: 스캔 타임, 타이머(100ms/10ms, FX 타이머 번호 규칙), 카운터, 상승/하강 에지, SET/RST, MPS/MRD/MPP, 비교 접점(LD= …), MOV/INC/ADD…, **STL 스텝 래더**, MC/MCR, 점프를 처리합니다.
- **설비 모델**: 실린더(싱글/더블 솔레노이드, 전진·후진 시간)와 지연 응답 모델이 출력에 반응해 센서 입력을 자동으로 만들기 때문에, 시작 버튼 한 번으로 **전체 사이클이 끝까지 진행**됩니다.
  실린더 동작은 차트에 **경사선(동작 시간)** 으로 그려집니다.
- **공정 스텝 자동 생성**: 스텝 번호 레지스터(D0, CASE Step 등)나 STL S 릴레이를 지정하면 공정 스텝과 사이클 타임이 자동 계산됩니다. ST에서는 `10: (* 클램프 *)`처럼 CASE 라벨에 단 주석이 스텝 이름이 됩니다.
- 디바이스 코멘트 CSV(GX Works 코멘트, XG5000 변수 목록)를 넣으면 신호 이름이 코멘트로 표시됩니다.
- 코드를 고쳐 다시 시뮬레이션해도 기존에 편집한 신호 이름, 색, 화살표, 규칙은 주소 기준으로 유지됩니다.

### 2. 타임차트 편집기
- 그리기 도구: 드래그하면 ON/OFF가 반전되고, `Shift`는 ON, `Alt`는 OFF로 그립니다. 선택 도구로는 에지를 드래그해 옮기고, 더블클릭으로 구간을 반전합니다.
- 신호 종류: 비트, 워드/데이터(스텝 번호 등), 아날로그(속도·압력), 클럭. 실린더·모터에는 전진/후진 같은 레벨 라벨과 동작 시간을 붙일 수 있습니다.
- 인과/인터록 화살표, 시간 치수선, 메모, 마커, 공정 스텝 구간, 그룹.
- 그리드와 **다른 신호의 에지에 자석처럼 스냅**, 커서 A/B Δt 측정, 에지 간 지연 측정, 구간 시간 삽입/삭제, 시간 스케일, 실행 취소/다시 실행.
- 파형 데이터를 표로 정밀하게 입력할 수 있습니다(시각, 값, 동작 시간).

### 3. 타이밍 규칙 검증
- **응답 시간**: A 에지 → B 에지가 최소/최대 시간 안인지 확인 (예: SOL ON → 전진단 센서 ≤ 400 ms)
- **인터록**: 두 신호의 동시 ON 금지 (예: 전진/후진 솔레노이드, 전진단/후진단 센서)
- **펄스 폭** 범위, **목표 사이클 타임**
- 위반 구간은 차트에 빨간색으로 표시되고, 보고서에 OK/NG 표로 들어갑니다.

### 4. 보고서 · 내보내기
- A4/A3, 가로/세로. 도면 **표제란**(회사, 제목, 설비, 도면번호, Rev, 작성/검토/승인, 페이지)과 변경 이력이 들어갑니다.
- 구성: 요약(사이클 타임, 규칙 결과), 타임차트(시간·신호 기준 자동 페이지 분할), 신호(I/O) 목록, 공정 스텝·사이클 타임(병목 표시), 규칙 검증, 인터록·주석 목록. 흑백 인쇄 모드를 지원합니다.
- PNG(고해상도), **클립보드 이미지 복사**(엑셀·파워포인트·한글에 붙여넣기), SVG 벡터.
- 엑셀용 CSV(UTF-8 BOM): 변화 시점표, 신호 목록, 스텝표.
- WaveDrom JSON 가져오기/내보내기, TCT 텍스트 형식.
- CSV 로그 가져오기: 데이터 로거나 트렌드 CSV(시간 열 + 신호 열, 날짜시간 형식 포함)를 불러와 실측 데이터로 차트를 만듭니다.

### 5. 텍스트 코드 (TCT 형식)
시간 기반 텍스트로 차트를 작성·버전 관리할 수 있습니다. WaveDrom처럼 틱 단위가 아니라 **실제 시간(ms/s)** 으로 씁니다.

```text
title: 클램프 공정
duration: 3s
grid: 50ms
group 클램프
sig Y0 "클램프 SOL" output : 0 | 300 1 | 2400 0
sig - "클램프 실린더" actuator on=전진 off=후진 : 0 | 300 1~300 | 2.4s 0~300
sig X1 "전진단" sensor : 0 | 600 1 | 2420 0
sig D0 "스텝" bus data : 0 | 300 10 | 600 20
step "S10 클램프" 300..600 "SOL ON → 전진단 확인"
arrow Y0@300 -> X1@600 "응답"
dim "클램프 실린더" 300..600
rule delay Y0 rise -> X1 rise max=400 "클램프 응답"
rule exclusive X1 X2 "센서 동시 ON 금지"
```

## 파일 형식
- `.tchart`: 프로젝트(JSON). 차트, 스텝, 주석, 규칙, PLC 소스와 시뮬레이션 설정이 모두 들어갑니다.
- `.tct`: 텍스트 형식. `.json`: WaveDrom. `.csv`: 로그 가져오기, 표 내보내기.
- 파일을 창에 끌어다 놓으면 열립니다. PLC 소스 파일(.txt, .csv, .st, .awl 등)은 PLC 탭으로 들어갑니다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트 (파형 연산, PLC 파서/시뮬레이터, 가져오기/내보내기)
npm run build      # 타입 검사 + dist/index.html (단일 파일) 생성
npm run release    # 빌드 후 release/TimeChartStudio.html 갱신
```

구성: React 19 + TypeScript + Zustand, Vite(단일 HTML 빌드), Vitest.

```text
src/model   파형 모델, 분석/규칙 검증, 템플릿
src/plc     PLC 파서(IL/STL/ST), 스캔 런타임, 시뮬레이터, 설비 모델
src/io      WaveDrom, CSV, TCT 텍스트, 파일 입출력
src/render  차트 SVG 렌더링(화면/보고서/이미지 공용)
src/components  편집기, PLC/텍스트/보고서 화면
```

## 시뮬레이션의 한계
- 래더(LD) 그래픽은 PLC 소프트웨어에서 **니모닉/IL 또는 CSV로 내보내서** 불러옵니다.
- 인덱스 수식, 파일 레지스터, 통신·위치결정 명령, 사용자 FB 정의 등 일부 명령은 무시되며, 무시된 명령은 경고로 표시됩니다.
- 시뮬레이션 결과는 설계 검토용입니다. 실제 설비의 응답 시간은 실측(CSV 로그 가져오기)으로 확인하세요.

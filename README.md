# TimeChart Studio

**제어 회로도를 그리면 타임차트와 부품 리스트가 자동으로 나오고, PLC 프로그램으로도 타임차트를 만들어 보고서(PDF)로 뽑는 무료 도구**입니다.
CADe SIMU 처럼 푸시버튼·릴레이·타이머·전자접촉기·전동기·공압 실린더로 결선도를 그리고 눌러서 움직여 볼 수 있습니다.

### ▶ 바로 쓰기: https://mioon1402.github.io/TimeChartForAutomation/

첫 주소는 무엇을 하는 도구인지 보여 주는 소개 페이지이고, **바로 시작하기**를 누르면 편집기(`…/TimeChartForAutomation/app/`)가 열립니다. 자주 쓰면 편집기 주소를 즐겨찾기하세요. 설치나 회원가입 없이 크롬·엣지에서 바로 열립니다. 인터넷이 막힌 PC에서는 [오프라인 파일(TimeChartStudio.html)](https://mioon1402.github.io/TimeChartForAutomation/TimeChartStudio.html)을 받아 더블클릭하세요.

![TimeChart Studio 화면: 드릴 가공 유닛 사이클 타임차트](public/og.png)

- 여는 PLC 프로그램과 차트는 **서버로 보내지 않습니다.** 모든 계산은 각자의 브라우저 안에서만 합니다.
- 문제 신고와 기능 제안은 [Issues](https://github.com/mioon1402/TimeChartForAutomation/issues)에 남겨 주세요.

## 1. 한눈에 보기 (처음 보는 분을 위한 설명)

### 타임차트가 뭔가요?
설비가 한 사이클 동안 **언제 무엇이 켜지고 꺼지는지**를 시간 순서대로 그린 그림입니다.
가로축은 시간, 세로로는 신호(버튼, 솔레노이드, 센서, 모터…)가 한 줄씩 놓입니다.

```text
시간 →            0      0.5s     1.0s     1.5s     2.0s
시작 버튼   X0   _|‾‾|__________________________________
클램프 SOL  Y0   ____|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|________
클램프 실린더    ____/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_______   ← 경사 = 움직이는 시간
전진단 센서 X1   _________|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|________
                 [S10 클램프][S20 가공 ......][S30 언클램프]  ← 공정 스텝
```

설비 사양서, 매뉴얼, 사이클 타임 검토, 고객 보고서에 들어가는 그림이 바로 이것입니다.

### 이 프로그램이 해 주는 일
0. **회로도 → 타임차트 · 부품 리스트**: 회로도 탭에서 결선도(전원, 차단기, 푸시버튼, 릴레이·MC 코일과 접점, 타이머, THR, 램프, 전동기, 솔레노이드, 공압 실린더, PLC 블록)를 그리고 버튼을 눌러 시뮬레이션합니다. "PB1 누름 → 3초 뒤 PB0 누름" 같은 조작 순서만 적으면 회로가 그대로 움직인 결과가 타임차트가 되고, 그림에서 부품 리스트(기호·품명·사양·접점 수·수량)가 자동으로 나옵니다.
1. **그리기**: 마우스로 ON/OFF 파형을 그립니다. 실린더 이동 시간은 경사선으로, 공정 스텝은 색 띠로 표시하고, "이 신호 때문에 저 신호가 켜진다"는 화살표와 시간 치수선을 넣을 수 있습니다.
2. **PLC 프로그램으로 자동 생성**: PLC 프로그램(래더를 니모닉으로 뽑은 것)을 넣거나 **래더를 직접 그리면** PLC가 도는 것처럼 계산해서 타임차트를 자동으로 그려 줍니다. LS XG5000은 **니모닉(IL)을 PDF로 인쇄한 파일을 그대로 열면** 됩니다.
3. **검토와 보고서**: 사이클 타임과 가장 오래 걸리는 스텝(병목)을 계산하고, "SOL이 켜지고 0.4초 안에 센서가 들어와야 한다" 같은 규칙을 자동으로 OK/NG 판정합니다. 결과는 도면 표제란(작성/검토/승인)이 있는 PDF 보고서로 뽑습니다.

### 이렇게 흘러갑니다

```text
 ┌──────────────────┐   ┌───────────────────┐   ┌─────────────┐   ┌──────────────┐
 │ PLC 프로그램      │   │ 시뮬레이션          │   │ 타임차트      │   │ 보고서        │
 │ · XG5000 IL PDF  │ → │ · 스캔 계산         │ → │ · 마우스 수정 │ → │ · PDF 인쇄    │
 │ · GX Works CSV   │   │ · 실린더/센서 응답   │   │ · 규칙 검증   │   │ · PNG / 엑셀  │
 │ · 직접 그리기     │   │   자동 흉내         │   │ · 사이클 타임 │   │              │
 └──────────────────┘   └───────────────────┘   └─────────────┘   └──────────────┘
```

## 2. 실행하기 (어디서 여나요?)

두 가지 방법이 있고, 기능은 똑같습니다.

| 방법 | 이럴 때 | 여는 법 |
|---|---|---|
| **웹 주소** | 인터넷이 되는 PC, 태블릿, 휴대폰 | https://mioon1402.github.io/TimeChartForAutomation/ (소개 페이지) → 바로 시작하기, 또는 편집기 바로 가기 `…/TimeChartForAutomation/app/` |
| **오프라인 파일** | 공장 PC, 사내망처럼 인터넷이 막힌 곳 | 파일 1개(약 2.5MB)를 받아서 더블클릭 |

### 웹 주소로 열기
- 첫 주소는 **소개 페이지**입니다. 무엇을 할 수 있는지, 타임차트가 처음인 사람을 위한 설명, XG5000 PDF 로 만드는 법이 있고, 이 브라우저에 하던 작업이 있으면 **이어서 작업하기** 버튼이 나옵니다.
- 소개 페이지의 버튼은 편집기의 원하는 화면으로 바로 갑니다: `app/#circuit`(회로도 탭, 예제 회로), `app/#tutorial`(차트 그리기 튜토리얼), `app/#tutorial-plc`(PLC 튜토리얼), `app/#practice`(연습 문제), `app/#wizard`(동작 순서 탭), `app/#plc`(PLC 탭).
- 크롬 또는 엣지를 권장합니다. 편집기를 처음 열면 시작 화면에서 **회로도 그리기 / 예제 차트 둘러보기 / PLC 프로그램으로 만들기 / 동작 순서표로 만들기** 중 하나를 고릅니다.
- 휴대폰에서도 열리지만, 편집과 보고서 출력은 마우스가 있는 PC가 편합니다.
- 새 기능이 나오면 같은 주소에서 바로 반영됩니다.

### 오프라인 파일 받기
- 웹 주소에서 오른쪽 위 `?`(도움말) → **오프라인 버전 받기**를 누르거나, [TimeChartStudio.html](https://mioon1402.github.io/TimeChartForAutomation/TimeChartStudio.html)을 바로 받습니다.
- 저장소의 `release/TimeChartStudio.html`과 같은 파일입니다.
- 받은 파일을 **더블클릭**하면 기본 브라우저로 열립니다. 인터넷 연결이 필요 없고, USB나 사내 공유 폴더로 다른 PC에 복사해서 써도 됩니다.

### 내 파일은 안전한가요?
- 여는 PLC 프로그램이나 차트는 **어디로도 전송되지 않습니다.** 웹 주소로 열어도 파일을 읽고 계산하는 일은 모두 내 브라우저 안에서만 합니다.

### 작업 내용은 어디에 저장되나요?
- **자동 백업**: 고친 내용은 브라우저에 자동으로 보관돼서, 창을 닫았다 다시 열어도 이어서 할 수 있습니다. 다만 같은 PC, 같은 브라우저에서만 남아 있습니다.
- **파일로 저장**: `Ctrl+S`를 누르면 `.tchart` 파일로 저장됩니다. 다른 PC로 옮기거나 보관할 때는 이 파일을 쓰세요. `Ctrl+O`로 다시 엽니다. 설비 하나의 차트 여러 장(자동 사이클, 원점 복귀 …)도 한 파일에 함께 저장됩니다.

## 3. 5분 따라하기

> **앱 안에 따라 하기 튜토리얼이 있습니다.** 처음 열면 나오는 시작 화면, 또는 오른쪽 위 `?`(도움말)에서 **차트 그리기 기초** / **PLC 프로그램으로 차트 만들기**를 누르세요. 누를 버튼을 하나씩 짚어 주고, 해 보면 저절로 다음으로 넘어갑니다. 끝나면 원래 차트로 돌아옵니다.

직접 읽으며 해 보려면:

1. **예제 보기**: 처음 열면 나오는 시작 화면에서 `예제 차트 둘러보기`를 누르면 "드릴 가공 유닛" 예제 차트가 나옵니다. 상단 `파일 → 템플릿`에서 로봇 핸드셰이크, 인버터 컨베이어 예제도 열 수 있습니다.
2. **파형 고치기**: 왼쪽 위 연필(그리기, `D` 키)을 누르고 신호 줄에서 마우스로 끌면 ON/OFF가 뒤집힙니다. 화살표(선택, `V` 키) 상태에서 파형이 바뀌는 지점을 끌면 시간이 옮겨집니다. 틀리면 `Ctrl+Z`로 되돌립니다.
3. **PLC 프로그램으로 만들기**: 상단 `PLC 시뮬레이션` 탭 → `예제 불러오기…`에서 "LS XGK - 픽앤플레이스"를 고르고 → 오른쪽 아래 `▶ 시뮬레이션 → 타임차트 생성`을 누릅니다.
4. **보고서 뽑기**: `보고서` 탭 → `인쇄 / PDF 저장`을 누르고 → 프린터를 "PDF로 저장"으로 고릅니다.

### 실물 배선도로 그리기 (차단기 · 전자접촉기 · 버튼 · 전동기를 실제 모양으로)

회로도 탭 왼쪽 위의 **[실물 배선]**을 고르면, 기호 대신 실제 기기 모양과 단자 번호로 배선합니다(실체 배선도). **[회로 기호]**를 고르면 시퀀스도 기호로 돌아갑니다. 둘을 한 회로에 섞어도 똑같이 시뮬레이션됩니다.

- 기기: 전원 단자(L1 L2 L3 N PE, +24V 0V, 속성에서 전원 계통: 3상 4선식 380/220 · 3상 3선식 380 · 220 · 단상 3선식 220/110 · 단상 2선식 220 V), 차단기 1P·2P·3P·4P(레버를 누르면 ON/OFF, 2P 이상은 속성에서 `누전차단기 (ELB)`로 바꾸면 빨간 표시와 노란 시험 버튼이 붙음), 전자접촉기(A1·A2 코일, 1/L1 3/L2 5/L3 → 2/T1 4/T2 6/T3, 보조 13-14 NO · 21-22 NC), 열동형 과부하 계전기(95-96 · 97-98, 눌러서 트립/복귀), 푸시버튼 유닛(버섯 머리, 11-12 b · 23-24 a), 셀렉터 스위치(손잡이 0 · 1, 11-12 b · 23-24 a), 비상정지(노란 판 + 빨간 버섯, 누르면 잠기고 다시 누르면 풀림), 파일럿 램프(X1 · X2), 3상 전동기(U V W + PE, 돌면 팬이 회전)
- **릴레이 · 타이머는 소켓에 꽂고, 전선은 소켓의 나사 단자에 물립니다.** 그림의 단자 줄은 실물 소켓을 위에서 본 것과 같아서 번호를 보고 그대로 배선하면 됩니다. 단자마다 번호 옆에 쓰임 (코일 · 전원 / C 공통 / a / b) 이 적히고 나사 링 색으로도 구분됩니다 (코일 주황 · 공통 노랑 · a 초록 · b 회색). 기호 (X1 · T1) 는 기기 위 스티커에, 부품 리스트에는 소켓 형식이 함께 나옵니다
  - 8핀 원형 소켓 (PF083A · 8PFA 꼴): **위 줄 6 5 4 3, 아래 줄 7 8 1 2**. 같은 소켓을 돌려 달았으면 속성의 `소켓 단자 배열` 에서 `위 2 1 8 7 · 아래 3 4 5 6` 을 고릅니다. 바꾸면 물려 있던 선은 같은 번호 단자를 따라가고 (비스듬해진 선은 다시 정리), 다른 단자에 닿게 되면 알려 줍니다. 예전에 그린 그림은 번호순 (위 1 2 3 4 · 아래 8 7 6 5) 그대로 열립니다
  - 각형 소켓 (PYF08A · PYF14A 꼴): 위 바깥 단 b (4 3 2 1), 안쪽 단 a (8 7 6 5), 아래 안쪽 단 공통 (12 11 10 9), 바깥 단 코일 (14 13). 2극은 `4 1 / 8 5 / 12 9 / 14 13`. 안쪽 단 나사는 선이 바깥 단 사이로 지나가도록 반 칸 옆에 그렸습니다 (번호는 실물과 같음)
  - 제조사 · 형식에 따라 소켓의 번호 자리가 다를 수 있으니 **소켓에 찍힌 번호를 기준으로** 배선하세요. 번호와 쓰임 (2-7 코일, 13-14 코일 …) 은 같습니다
- **8핀 릴레이 + 소켓** (MK2P 꼴): 2-7 코일, 1-3 a · 1-4 b, 8-6 a · 8-5 b. 덮개에 내부 결선도가 그려져 있고, 동작하면 접점 날이 a 쪽으로 넘어갑니다
- **각형 릴레이 2c · 4c + 소켓** (MY2N · MY4N 꼴): 13-14 코일, 공통 9~12, a 5~8, b 1~4. 같은 세로줄의 세 단자가 한 벌 (9-5 a · 9-1 b …). 덮개 안에 줄마다 접점 날이 그려져 있고 동작 표시등이 켜집니다
- **8핀 타이머 + 소켓**: 2-7 전원, 8-6 한시 a · 8-5 한시 b, 1-3 · 1-4 는 한시(기본) 또는 순시(속성에서 체크). 다이얼에 설정 시간이 보이고, 시뮬레이션 중에는 지난 시간이 다이얼에 차오릅니다. ON 딜레이 · OFF 딜레이 · 플리커 · **인터벌 (원샷)**: 전원이 들어오면 바로 붙고 설정 시간 뒤 떨어짐 (전원이 계속 있어도). "센서가 감지하면 솔밸브를 3초만" 같은 데 씁니다. 플리커는 **켜짐 시간 · 꺼짐 시간을 따로** 넣을 수 있습니다 (트윈 타이머, 예: 2초 ON · 5초 OFF 반복. 꺼짐 시간을 비우면 켜짐과 같음)
- 소켓 단자 번호는 위 1 2 3 4, 아래 8 7 6 5 로 그렸습니다. 소켓마다 번호 배치가 다를 수 있으니 실제로는 **소켓에 찍힌 번호**를 보고 같은 번호에 물리세요
- **단자대**: 번호마다 위·아래 나사가 이어져 있습니다. 극수는 속성에서 1~40 으로 바꿉니다. 판넬 안 기기는 아래 나사, 문(도어)에 붙는 버튼·램프는 위 나사로 이으면 실제 제어반처럼 됩니다
- 전선 색: 단자에서 끌어 선을 그으면 전원 극을 따라가 표준 색이 자동으로 붙습니다(L1 갈색, L2 검정, L3 회색, N 파랑, PE 녹황, +24V 빨강). 선을 고르면 오른쪽에서 색을 바꿀 수 있습니다.
- 시뮬레이션 중 전압이 닿은 전선 위로 흰 점선이 흐르고, 전자접촉기 창이 들어가며 램프가 켜지고 전동기 팬이 돕니다. L 이 PE 에 닿으면 지락(단락)으로 알려 줍니다.
- 예제: `예제 회로 → 실물 배선도: 전동기 기동·정지` (차단기 3P·2P, 전자접촉기 자기유지, 정지·기동 버튼, 전동기 PE 접지)
- 예제: `예제 회로 → 제어반 실물 배선: 릴레이 · 타이머 · 단자대` (문: 비상정지 · 셀렉터 · 정지/기동 버튼 · 정지/운전/대기 램프 ↔ 단자대 TB1 ↔ 판넬: 차단기 1P · 8핀 릴레이 X1 · 8핀 타이머 T1. 기동하면 대기 램프, 3초 뒤 운전 램프)
- 예제: `예제 회로 → 릴레이 소켓 배선: 각형 릴레이 자기유지` (MY2N 꼴 릴레이를 PYF08A 꼴 소켓에: 정지 · 기동 버튼 → 코일 14, 9-5 자기유지, 12-8 운전 램프, 12-4 정지 램프)

### 현장 기기 목록 (실물 배선)

왼쪽 목록의 `실물 배선`에서 종류별로 고릅니다. 목록에 있는 것은 모두 시뮬레이션에서 동작하고, 누르면 속성 아래에 쓰는 법이 나옵니다.

| 묶음 | 기기 |
|---|---|
| 보호 장치 | 차단기 1P~4P, 누전차단기 2P~4P, **퓨즈 홀더**, 열동 계전기 THR |
| 제어 기기 | 전자접촉기, 8핀 릴레이 · 각형 릴레이 2c/4c (소켓), 8핀 타이머 (ON 딜레이 · **OFF 딜레이** · **플리커** · **인터벌**), **프리셋 카운터** (A1 · A2 전원, 무전압 입력 CP · COM · RST, 출력 C · NO · NC, 설정 수는 속성), **온도 조절기** (A1 · A2 전원, 출력 C1-OUT · 경보 C2-AL), **온도 조절기 8핀 (T3S 꼴, 48×48 · 8핀 소켓: 전원 L · N AC 100-240V, 측온저항체 입력 A · B · B', 릴레이 출력 COM-NO · COM-NC)**, **판넬 서모스탯** (NC 히터용 · NO 팬용), **SSR** (입력 3 + · 4 - DC, 출력 1-2 AC), 24시간 타임 스위치, **솔레노이드 밸브** (5포트 공압 밸브 + 코일. 코일에서 리드선 2가닥: 직류는 빨강 + · 검정 -, 교류는 극성 없음. 속성에서 DIN 커넥터 (1 · 2 · PE) 로 바꿀 수 있고 코일 전압을 고름, 비우면 DC 24V) |
| 스위치 · 푸시버튼 | 푸시버튼 (녹 · 적 · 황), **조광형 푸시버튼** (접점 + 램프 X1-X2), 셀렉터, **3단 셀렉터** (수동 · 정지 · 자동: 왼쪽 13-14, 오른쪽 23-24, 자리 이름은 속성에서), 비상정지, **풋 스위치**, **리밋 스위치**, 스위치 · 3로 스위치 |
| 센서 | **근접 센서 PNP · NPN (3선식: 갈색 + · 검정 출력 · 파랑 0V)**, **근접 센서 2선식 (DC 12-24V · AC 100-240V, NO/NC: 갈색 · 파랑을 부하와 직렬로, 직류는 갈색이 + 쪽)**, **광전 센서**, **플로트 스위치**, **압력 스위치**, **측온저항체 Pt100 (3선식: A 빨강 · B · B' 흰색 두 가닥)** |
| 표시 · 부하 | 램프, **부저**, 전등, **콘센트**, **판넬 팬**, 3상 전동기, **3상 전동기 6단자 (Y-Δ 기동)**, 부하 단상 · 3상 (히터 · 열풍기, 속성에서 **외함 접지 단자 PE** 를 붙일 수 있음) |
| 전원 · 계측기 | **SMPS (DC 24V)**, **전압계**, **전류계** (시뮬레이션 중 값이 나옴) |
| 배선 자재 | 단자대, **중성선 바 (N) · 접지 바 (PE)**, **배선 덕트**, **DIN 레일** |
| 수전 · 분전반 | 한전 수전 · VCB · 변압기, 분전반 테두리 · 부스바 · 부하 |
| PLC · HMI (제어반) | **PLC** (CPU 일체형, 입력 16 · 릴레이 출력 16: 전원 + · − · FG, 입력 공통 COM, 출력 공통 COM0 · COM1), **HMI (터치 판넬)** (전원 + · − · FG, 화면 버튼 · 스위치 · 램프가 PLC 디바이스와 통신) |

- **배선이 실물처럼 보입니다**: 나사 단자에 물리는 선 끝에 압착 단자가 그려지고, 이어지지 않고 엇갈리는 선은 작은 다리 (반원) 로 넘어갑니다. 덕트를 놓으면 선이 덕트 안으로 지나가는 모양이 되고, DIN 레일은 기기 밑에 깔립니다 (둘 다 손잡이를 끌어 길이 조절, 전기적으로는 아무것도 하지 않음).
- 3단 셀렉터는 속성의 **지금 자리**로 시뮬레이션을 시작하고 (없으면 가운데), 시뮬레이션 중에 손잡이의 왼쪽 · 오른쪽을 눌러 돌리고, 같은 쪽을 한 번 더 누르면 가운데로 돌아옵니다. 조작 순서표에서는 동작을 `← 수동` · `정지` · `자동 →` 으로 고르고, 타임차트에는 자리 이름으로 나옵니다.
- 카운터는 CP-COM 이 이어질 때마다 하나씩 세고 (무전압 접점 입력, 전원 A1 · A2 가 있을 때만), 설정 수에 닿으면 C-NO 닫힘 · C-NC 열림을 리셋 (RST-COM) 까지 유지합니다. 타임차트에 `카운터` 묶음으로 센 수와 출력이 나옵니다. 단자 이름은 기능으로 적었으니 실물은 기기 옆면의 결선도를 따르세요.
- **온도 조절기 (48×48)**: A1 · A2 전원, C1-OUT 제어 출력, C2-AL 경보 출력 (릴레이 a접점). 앞면에 지금 온도 PV (빨강) 와 설정 온도 SV (초록), OUT · AL 램프. 속성에서 설정 온도 · 히스테리시스 · 경보 온도와 가열 / 냉각 동작을 정합니다. 가열이면 `설정 − 히스테리시스` 이하에서 OUT 이 닫히고 설정 온도에서 열립니다. OUT 으로 전자접촉기 · SSR 코일을 켜서 히터를 개폐합니다
- **온도 조절기 8핀 (T3S 꼴)**: 숫자를 돌려 맞추는 썸휠 설정 (예: 오토닉스 T3S-B4RP2C-N, Pt100 0~200℃, 릴레이 출력). 위쪽 A · B · B' 에 측온저항체 세 가닥 (A = 빨강, B · B' = 흰색 두 가닥, 둘은 바꿔 물려도 됨), 아래쪽 L · N 전원과 출력 COM-NO (온도가 낮으면 닫힘) · COM-NC. 측온저항체가 빠지거나 A 와 B 를 섞어 물리면 화면에 `oPEn` 이 뜨고 출력을 끕니다 (센서 끊김). 센서 단자에 전원이 닿으면 [검사] 가 오류로 알립니다. **단자 번호는 기능 이름으로 적었으니 실물은 제품 옆면 · 설명서의 결선도 (소켓 PG-8 단자 번호) 를 따르세요.**
- **측온저항체 (Pt100, 3선식)**: 보호관 · 나사 고정 프로브. 세 번째 가닥 (B') 으로 리드선 저항을 빼서 선이 길어도 온도가 틀어지지 않습니다. 조절기의 A · B · B' 와 같은 이름끼리 잇습니다
- **판넬 서모스탯 (바이메탈)**: 단자 1 · 2 뿐인 무전압 접점. NC (빨간 다이얼) 는 히터용으로 온도가 설정에 닿으면 열리고, NO (파란 다이얼) 는 팬용으로 닫힙니다. 회로 기호에는 **온도 스위치** (오르면 닫힘 / 열림, 작동부에 θ) 가 있습니다
- **시뮬레이션의 온도**: 속성의 [온도를 바꾸는 부하] 에 히터 (또는 팬) 기호를 고르면, 히터가 켜져 있는 동안 [오르는 속도] 로 오르고 꺼지면 [내리는 속도] 로 주위 온도까지 내려갑니다 (팬은 반대: 돌면 식음). 조작 순서에는 `온도 →` 동작이 있어서 "판넬 온도 → 40℃, 15초 동안" 처럼 바꿀 수 있고 (0 초면 바로), 시뮬레이션 중에는 기기의 왼쪽 · 오른쪽을 눌러 5℃씩 내리고 올립니다. [온도 묶음 이름] 이 같은 기기는 같은 온도를 잽니다 (한 판넬 안의 서모스탯 두 개). 타임차트에는 온도가 선 (아날로그) 으로, 그 아래에 OUT · AL · 서모스탯 접점이 나옵니다
- **PLC (실물)**: DC 24V 가 + · − 에 들어와야 돌고 (PWR · RUN 램프), 전원이 끊겼다 들어오면 처음부터 다시 돕니다 (자기유지가 풀림). 입력은 COM 과 반대 극이 닿으면 ON (COM = 0V 면 싱크, +24V 면 소스), 출력은 COM0 (0~7) · COM1 (8~15) 과 이어지는 릴레이 접점입니다. 주소 (P00000 / X0 …) 는 속성에서 정하고 단자 이름도 그 주소로 나옵니다. 프로그램은 PLC 시뮬레이션 탭 (니모닉 · 래더) 의 것을 스캔마다 실행합니다
- **HMI (터치 판넬)**: 속성에서 화면 칸 (최대 12) 을 버튼 (누르는 동안 1) · 스위치 (누를 때마다 1 ↔ 0) · 램프 (디바이스가 1 이면 켜짐) 로 정하고 PLC 디바이스 (M00100 …) 를 적습니다. 선은 전원만 잇고 PLC 와는 통신으로 이어집니다. 시뮬레이션 중에 화면 버튼을 누르면 PLC 가 다음 스캔에 읽고, 조작 순서표에서는 `HMI1-1`, `HMI1-2` … (칸 번호) 를 고릅니다. HMI 전원이 없거나 PLC 가 멈추면 "통신 이상" 이 되어 버튼이 듣지 않습니다
- **PLC 가 상하지 않게 [검사] 가 보는 것**: 입력에 교류 (AC 220V) 가 닿음 (DC 24V 입력이 탐) · 입력 공통 COM 빠짐 · 출력 공통에 퓨즈 · 차단기가 없음 (출력 쪽 단락 때 접점이 녹아 붙음) · 출력 접점으로 전자접촉기 코일 · 전동기 · 교류 솔레노이드를 바로 켬 (돌입 전류 · 서지 → DC 24V 보조 릴레이를 거치라고 알림) · HMI 버튼이 PLC 입력 주소에 씀. PLC · HMI 의 FG 접지 빠짐, DC 24V 정격과 다른 전원도 함께 봅니다
- 아직 없는 것: 인버터, EOCR, 플로트리스 릴레이 (전극식), 전력량계 · 변류기. 필요하면 알려 주세요.

### 회로도 → 실물 배선도 자동 생성 (배치 · 배선 길이)

회로 기호로 회로도를 그렸으면 회로도 탭 위쪽 **[실물 배선도 만들기]** 를 누르세요. 기호를 실제 기기로 바꿔 판넬처럼 놓고 전선을 모두 그어 **새 차트 탭** 에 엽니다. 원래 회로도는 그대로입니다.

- **기기 고르기**: 코일 + 접점 → 8핀 릴레이 (접점 2개까지, a · b 가 공통을 같이 쓰면 한 벌로) → 모자라면 각형 4c 릴레이 → 그래도 모자라면 코일을 나란히 단 **보조 릴레이** (X1-2). 전자접촉기는 주접점 3극 + 보조 13-14 a · 21-22 b, 타이머는 8핀 (순시 접점이 있으면 1-3 · 1-4 를 순시로), 버튼 · 셀렉터 · 비상정지 · 리밋 스위치는 1a1b, 2선식 근접 센서 · 서모스탯은 접점 하나, THR 은 주회로 + 95-96 · 97-98. 램프 · 부저 · 솔레노이드 · 전동기 · SMPS · 차단기 · 퓨즈도 실물로, 직류 회로의 코일 · 램프는 사양을 DC 24V 로 적습니다. 공압 기기 · PLC 블록은 그대로 옮기고 배관도 다시 긋습니다.
- **배치**: 위에서 아래로 전원 단자 → 차단기 · 퓨즈 → 제어 기기 (접촉기 · THR · 릴레이 · 타이머 · SMPS) → 문 (버튼 · 램프) → 현장 기기 (전동기 · 센서 · 밸브). 줄 안의 차례는 **전선 길이가 가장 짧아지도록** 바꿔 봅니다.
- **배선**: 단자마다 이어야 할 곳을 격자 위 길 찾기로 잇습니다. 다른 전선의 끝이나 단자에는 닿지 않고 엇갈려 지나가기만 해서, 그린 그림의 연결은 회로도와 **꼭 같습니다** (내장 예제 모두 연결 · 타임차트가 같은지 테스트로 확인). 전선 색은 극을 따라 (L1 갈색, N 파랑, PE 녹황, +24V 빨강 …).
- 회로도에서 제어 회로가 차단기 없이 전원에 바로 물려 있으면 **제어 전원 차단기 (CB0)** 를 넣고, 전동기 · SMPS 가 있으면 **PE 단자** 를 더해 접지선을 잇습니다. 무엇을 바꿨는지는 알림으로 나옵니다.
- **배선 다시 그리기**: 만든 배선도에서 기기를 실제 판넬 자리로 끌어 옮긴 뒤 위쪽 **[배선 다시 그리기]** (또는 [결선표] 탭의 버튼) 를 누르면, 연결은 그대로 두고 전선을 가장 짧게 다시 긋고 **전선 길이 (전 → 후)** 를 알려 줍니다. [결선표] 탭 위에 지금 그림의 전선 합계가 늘 나옵니다 (그림 1칸 = 1 cm 로 어림). 기기 자리를 바꿔 가며 선이 덜 드는 배치를 찾을 때 쓰세요. 손으로 그린 실물 배선도에도 됩니다 (부스바가 있는 그림은 빼고).
- 아직 단자대 (판넬 ↔ 문 · 현장) 는 넣지 않습니다. 필요하면 직접 넣고 [배선 다시 그리기] 를 누르세요.

### 실물 배선도 → 회로도 자동 생성

실물 배선도를 그렸으면 회로도 탭 위쪽 **[회로도 만들기]** 를 누르세요. 같은 회로를 회로 기호 (전개 접속도) 로 다시 그려 **새 차트 탭** 에 엽니다. 원래 그림은 그대로입니다.

- 그림의 선 모양이 아니라 **어느 단자끼리 이어졌나** 만 보고 다시 그립니다. 그래서 선이 엉켜 있어도 회로도는 위 (L) 에서 아래 (N) 로 정리됩니다.
- **조작 회로**: L → 차단기 · 퓨즈 · THR b접점처럼 공통으로 지나는 것은 맨 위에 한 번, 그 아래로 코일 · 램프마다 한 줄씩 내려가고 코일 · 램프는 아래 한 줄에 맞춰 놓습니다. 자기유지 접점 · 인터록 b접점이 병렬 · 직렬로 그대로 나옵니다.
- **주회로 (3상)**: 전원 → 차단기 → 전자접촉기 → THR → 전동기. 정 · 역 운전의 상 바꿈, Y-Δ 기동의 Δ · Y 접촉기도 그립니다.
- **단자 번호는 실물 기기 번호**로 적습니다 (8핀 릴레이 1-3, 타이머 8-6, 각형 릴레이 코일 13-14 …). 3단 셀렉터 접점에는 자리 이름 (수동 · 자동) 이 붙습니다.
- **직류 24V**: SMPS 출력이 직류 회로의 +24V · 0V 가 되고, 3선식 센서의 파랑 (0V) 은 아래 0V 선에 잇습니다.
- 조작 순서도 같이 옮기므로 회로도 탭에서 시뮬레이션하면 **타임차트가 실물 배선도와 같습니다** (내장 예제 모두 테스트로 확인).
- 직렬 · 병렬로 정리되지 않는 회로 (브리지) 는 코일마다 전원에서 오는 길을 모두 나란히 그립니다 (같은 접점이 여러 번 나옴).
- 아직 회로도 기호가 없어 빠지는 것: 타임 스위치, 카운터, PLC, 공압 밸브, 한전 수전 · VCB · 변압기. 빠진 것은 알림으로 알려 줍니다.

### 배선 검사 (잘못 이은 곳 찾기)

**[검사] 탭**이 그림을 실제로 배선했을 때 생기는 잘못을 시뮬레이션 없이 찾아 줍니다. 줄을 누르면 그 기기 · 전선이 그림에서 표시됩니다.

| 찾는 것 | 예 |
|---|---|
| 전원까지 이어지지 않는 부하 | 코일 한쪽 선이 빠짐, 두 단자가 모두 L 에만 물림, 교류와 직류가 섞임, 부하끼리 직렬, 전동기 결상 |
| 정격 전압과 다른 전압 | AC 220V 릴레이를 DC 24V 에, 110V 기기를 220V 에. 정격은 속성의 `사양` 에 적은 글 (AC 220V · DC 24V · AC 100~240V) 에서 읽습니다 |
| 단락 | 전원 극끼리 부하 없이 선 (차단기 · 퓨즈) 으로만 이어짐 |
| 끝이 떠 있는 선 | 단자까지 닿지 않은 선 |
| 나사 하나에 3가닥 이상 | 보통 2가닥까지: 단자대나 점퍼로 나누기 |
| 보호 장치 없음 | 전원 상이 차단기 · 퓨즈 없이 바로 기기에 |
| 접점이 N 쪽에 있음 | 부하의 L 쪽이 바로 물려 있어서 꺼도 전압이 남음 |
| 접지 빠짐 | 전동기 · 콘센트 · SMPS 의 PE (FG) 단자 |
| 전선 색 | N 인데 파랑이 아님, 녹황을 접지 아닌 곳에, 상 색 (갈 · 흑 · 회) 이 바뀜. 제어선 색 (빨강 · 노랑 …) 은 자유 |
| 센서 · SMPS · SSR · 카운터 · 솔레노이드 | 센서 극성 반대 (갈색 = +, 파랑 = 0V), **직류 솔레노이드 리드선 반대 (빨강 = +)**, **교류 솔레노이드 DIN 커넥터 접지 빠짐**, **2선식 센서를 부하 없이 전원에 바로 이음 (켜지면 단락) · 직류 2선식 극성 반대 · 교류용 / 직류용이 회로와 다름**, SMPS 입력 빠짐, SSR 입력 극성 반대 (3 = +, 4 = -), 카운터의 무전압 입력에 전원이 닿음 |

- 접점은 "닫힐 수 있다" 고 보고 길을 찾으므로, 조작 순서를 넣지 않아도 선이 빠진 곳이 나옵니다.
- 찾지 못하는 것: 정역 인터록 누락 (시뮬레이션에서 두 접촉기가 함께 붙으면 단락으로 알려 줌), 전선 굵기 (이것은 [해석] 탭), 기호 회로의 모선 끝.

### 예제 프로젝트

`예제 회로` 메뉴는 종류별 **폴더**로 나뉘어 있습니다. 폴더를 누르면 그 자리에서 펼쳐지고 (한 번에 하나, 다시 열면 마지막 폴더가 펼쳐진 채로), 창이 작아 다 안 보이면 메뉴 안에서 스크롤됩니다. 모두 [검사] 문제 없이 동작하는 완성 회로이고, 열면 조작 순서와 타임차트가 함께 들어옵니다.

- **전동기 제어 (실물 배선)**: 조그 (인칭) 운전 · **조그 + 연속 운전** (보조 릴레이가 기동을 기억, 조그는 누르는 동안만) · 표시등 부착 자기유지 (운전 · 정지 · 과부하등) · 2개소 (다점) 제어 · **리밋 스위치 자동 정지** (끝에 닿으면 LS b접점이 자기유지를 끊음) · **정 · 역 운전 이중 인터록** (버튼 b접점 + 접촉기 b접점, L1 · L3 을 바꿔 역회전) · **자동 Y-Δ 기동** (접촉기 3개 · 타이머 · 인터록, 6단자 전동기) · 급수 펌프 (플로트 스위치 자동 / 수동) · **급수 펌프 수동 · 정지 · 자동** (3단 셀렉터: 수동은 버튼 자기유지, 자동은 플로트) · 기동 · 정지
- **제어반 · 릴레이 · 센서**: **PLC 제어반: 펌프 2대 (로컬 · HMI)** (아래 설명) · 제어반 실물 배선 (단자대) · 릴레이 소켓 배선 · **직류 24V (SMPS → 근접 센서 → 릴레이 → 솔레노이드 밸브 · 부저)** · **솔레노이드 밸브 2개 교번** (플리커 타이머의 a · b 접점이 1초마다 번갈아) · **생산 수량 카운터** (리밋 스위치 3번 → 완료등, 리셋 버튼) · **SSR 로 히터 켜기** (DC 24V 스위치 → SSR → 교류 히터 2 kW) · **2선식 근접 센서** (DC: +24V → 갈색, 파랑 → 램프 → 0V · AC: L → 차단기 → 센서 → 램프 → N) · **히터 온도 제어** (온도 조절기 OUT → 전자접촉기 → 히터 2 kW 로 60℃ 유지, 85℃ 로 올린 과열 시험에서 AL 경보등) · **판넬 온도 관리** (35℃ 면 팬 · 5℃ 면 결로 방지 히터, 판넬 온도를 여름 낮 · 겨울 밤처럼 천천히 바꿔 봄)
- **전등 · 주거**: 타임 스위치 전등 · 3로 스위치 계단등 · **타이머 지연 점등** (8핀 타이머 한시 a접점, 스위치를 켜고 3초 뒤) · **주거 배선 (누전차단기 · 스위치 · 전등 · 콘센트, 중성선 바 · 접지 바)**
- 제어반 묶음에 **열풍기 온도 제어 + 24시간 타이머 (전기 요금)** (아래 설명) 도 있습니다
- **분전반 · 계통 해석**: 분전반 · 부스바 · 급전 · 수전 · 변압기 해석, **누전 · 지락: 접지와 누전차단기 (TT)** (아래 설명)
- **기호 회로 (시퀀스 · 공압 · PLC)**: 기호 회로에는 **센서 감지 → 솔밸브 3초만** (인터벌 타이머: 계속 감지해도 3초 뒤 꺼짐, 감지가 짧으면 그때 꺼짐) 도 있습니다

### PLC 제어반 예제: 급수 펌프 2대 (로컬 · HMI 원격)

실제로 설계하듯 그린 제어반입니다 (예제 회로 → 제어반 · 릴레이 · 센서 → **PLC 제어반**). PLC 프로그램은 LS XGK 니모닉이고 PLC 탭에서 래더로 열립니다.

- **주회로**: 3상 380V → 주 차단기 MCCB → 펌프마다 MCB → 전자접촉기 MC → 열동 계전기 THR → 전동기, 접지는 접지 바 PEB 의 나사 하나에 기기 하나씩
- **조작 전원**: CB1 (2P, AC 220V) → SMPS (DC 24V) → 퓨즈 F1 (PLC · HMI 전원) · F2 (입력 · 현장 신호) · F3 (출력 공통 COM0). 전선 색은 주회로 L1 갈색 · L2 검정 · L3 회색, N · 0V 파랑, AC 조작 노랑, DC 24V 빨강, 접지 녹황
- **PLC 를 지키는 배선**: 입력은 모두 DC 24V (싱크, COM = 0V). PLC 출력은 퓨즈를 거친 COM0 에서 **DC 24V 보조 릴레이 RY1 · RY2 (인터포징, 다이오드 내장)** 와 LED 램프 · 부저만 켜고, AC 220V 전자접촉기 코일은 릴레이 접점이 켭니다
- **PLC 가 고장 나도 멈추게**: 비상정지 EMG (11-12) 와 THR (95-96) 이 MC 코일 회로를 직접 끊습니다. PLC 는 EMG 23-24 · THR 97-98 · MC 보조 13-14 로 상태만 읽습니다 (타임차트에서 MC 가 먼저 떨어지고 PLC 지령은 한 스캔 뒤에 꺼지는 것이 보임)
- **운전 장소**: 문의 COS (SS1: 로컬 · 정지 · 원격). 로컬이면 문 버튼으로만, 원격이면 HMI 로만 기동하고, **정지는 어디서나** (문 정지 버튼은 b접점으로 받아 선이 끊겨도 정지 쪽). COS 를 가운데 (정지) 에 두면 모두 멈추고 어떤 기동도 받지 않습니다. 예제는 **로컬 자리에서 시작**하니 시뮬레이션을 켜고 문의 PB11 · PB21 을 바로 눌러 보세요. HMI 로 돌리려면 SS1 손잡이의 오른쪽을 눌러 원격으로 돌립니다 (HMI 화면의 `로컬 (문)` · `원격 (HMI)` 램프가 지금 자리를 보여 줌)
- **고장 처리**: 과부하 · 비상정지 · MC 이상 (지령 뒤 2초 안에 MC 보조 접점이 안 들어옴) 을 기억하고 고장등을 0.5초 점멸 · 부저. 리셋 (문 버튼 · HMI) 은 원인이 남아 있으면 부저만 끄고, 원인이 없어진 고장만 풉니다. 비상정지를 풀어도 다시 돌지 않고 리셋 뒤 기동해야 합니다
- **HMI 화면**: P1 · P2 기동 / 정지, 고장 리셋 버튼과 P1 · P2 운전, 로컬 · 원격 (지금 운전 장소), P1 · P2 고장, 비상정지 램프
- 조작 순서는 로컬 운전 → 로컬에서 HMI 기동 (무시됨) → 원격으로 HMI 운전 → P2 과부하 · 리셋 → 비상정지 · 리셋 → COS 정지까지 23초를 보여 줍니다. [검사] 탭은 문제가 없고, 일부러 PLC 출력으로 MC 코일을 바로 켜 보면 경고가 나옵니다

### 부품 쓰는 법이 궁금할 때

- 왼쪽 목록에서 부품을 누르면 오른쪽 **[속성]**에 **이 부품 쓰는 법**이 나옵니다: 무엇을 하는 기기인지, 단자마다 무슨 뜻인지, 어떤 순서로 잇는지, 시뮬레이션에서 어떻게 움직이는지. 그림에 놓인 부품을 눌러도 속성 아래에 같은 안내가 나옵니다.
- **[이 부품을 쓴 예제 열기]**를 누르면 그 부품이 실제로 배선된 예제가 새 차트 탭으로 열립니다 (지금 그리던 그림은 그대로).
- 단자 위에 마우스를 올리면 `MC1 13NO` 처럼 어느 기기의 몇 번 단자인지 뜹니다.
- 예: **전자접촉기**는 "전기로 누르는 큰 스위치"입니다. A1 · A2(코일)에 전압이 걸리면 주접점(1/L1→2/T1 …)과 보조접점(13-14 a, 21-22 b)이 함께 바뀝니다. 주회로는 차단기 → 1/L1 · 3/L2 · 5/L3, 2/T1 · 4/T2 · 6/T3 → 전동기. 코일은 A1 → N, A2 → 정지(b) → 기동(a) → L. 기동 버튼과 나란히 13-14 를 이으면 자기유지.
- 왼쪽 위 **[실물 배선 | 회로 기호]** 전환 버튼은 목록을 내려도 위에 붙어 있습니다.

### 타임 스위치로 전등 자동 점멸 (24시간 다이얼식)

`실물 배선 → 전등 · 타임 스위치`에 **24시간 타임 스위치**, **전등**, **스위치(단로)**, **3로 스위치**가 있습니다.

1. 전원 L · N → 차단기 2P
2. 차단기 아래 L → 타임 스위치 **L**, N → 타임 스위치 **N** (시계 전원: 늘 전압이 있어야 다이얼이 돕니다)
3. 타임 스위치 L 에서 **COM** 으로 점퍼선 하나
4. **NO** → 전등 L, 전등 N → N

- 켜지는 시간은 타임 스위치를 누르고 속성의 **켜지는 시간 (ON 구간)**에서 정합니다 (15분 단위, 여러 구간, `18:00 → 06:00` 처럼 자정을 넘겨도 됩니다). 다이얼 가장자리의 주황색 세그먼트가 켜지는 구간입니다.
- **[시뮬레이션]**을 누르면 1초에 1시간씩 흐르고(속도는 ×60 · ×600 · ×3600 중에서), 다이얼 바늘과 시각 표시가 돌다가 설정 시각에 전등이 켜지고 꺼집니다. 차단기를 내리면 시계가 멈춰서 그만큼 늦어집니다(정전 보상이 없는 기계식 기준).
- 타임차트는 하루(0~24시)가 시간 단위로 그려집니다. 시작 시각은 `조작 순서 → 시작 시각`에서 바꿉니다. 조작의 대기 시간은 `6h`, `30min` 처럼 적을 수 있습니다.
- 예제: `타임 스위치로 전등 자동 점멸 (기본)`, `타임 스위치 + 자동/수동 + 전자접촉기` (전등이 많을 때: 타임 스위치는 MC 코일만 켜고 셀렉터로 수동 점등), `3로 스위치 계단등`
- 타임 스위치는 제품마다 단자 이름과 배치가 다릅니다 (전원 2개 + 접점 COM · NO · NC 가 일반적). 실제로는 제품 옆면 결선도를 보고 같은 뜻의 단자에 물리세요.

### 분전반을 박스로 나누고 케이블까지 해석하기 (전류 · 허용전류 · 전압강하)

다른 도면 번호를 적어 넘기는 대신, **분전반 · 변전함을 테두리 상자**로 한 그림에 놓고 그 사이를 급전선으로 이으면 전체가 함께 시뮬레이션됩니다. 전선마다 케이블 규격을 정하면 [해석] 탭이 문제를 찾아 줍니다.

1. `실물 배선 → 분전반 · 부하 (해석)`에서 **분전반 · 변전함 (테두리)**를 놓고, 안에 차단기를 놓습니다. 이름표 줄을 잡고 끌면 안의 기기와 선이 함께 옮겨집니다. **크기는 테두리를 누른 뒤 오른쪽 아래 모서리의 네모 손잡이를 끌어** 바꿉니다 (속성의 가로 · 세로 칸 수로도 됨). 기기가 많으면 넉넉하게 키우세요.
2. **부하 (3상 · 단상)** 상자를 놓고 용량 (kW) 과 역률을 적습니다. 히터 · 컴프레서 같은 기기 하나, 또는 아래쪽 분전반 전체를 한 덩어리로 나타냅니다. 전동기 · 전등도 부하로 계산됩니다 (전동기는 정격 출력 · 역률 · 효율).
3. **전선을 누르고** 속성의 `케이블 규격`에서 절연 (PVC 70℃ · XLPE 90℃), 굵기 (mm²), 공사방법 (A1~F), 부하 도체 수, 길이 (m), 주위 온도, 함께 지나는 회로 수를 정합니다. 3상은 세 가닥을 Shift+클릭으로 함께 골라 같은 값을 줍니다. 꺾여 이어진 한 가닥 전체에 적용됩니다.
4. **부스바**는 `분전반 · 부하 (해석)`의 **부스바 4극 (L1 L2 L3 N) · 3극**을 놓습니다. 구리 막대가 2칸 간격으로 서 있어서 4P 메인 차단기 아래 단자와 곧게 이어지고, 위 끝이 단자입니다.
   - **분기 (탭)**: 분기 차단기를 옆으로 돌려 (R) 놓고, 전원 쪽 단자에서 **자기 상 막대까지 가로선을 긋습니다.** 선 끝이 닿은 막대에만 볼트 점이 찍히며 물리고, 그 앞의 다른 막대 위를 지나가는 것은 닿지 않습니다 (실물처럼 짧은 동바나 전선으로 탭을 뽑는 모양). 막대를 누르고 끌면 그 자리에서 분기선이 바로 시작됩니다.
   - 길이는 부스바를 누른 뒤 **아래 끝 손잡이를 끌어** 바꾸고, 속성에서 막대 수 · 단면적 (mm²) · 정격 전류 (A, 제조사 값) 를 적습니다. 부스바를 옮기면 물린 분기선도 따라옵니다.
   - 예전처럼 전선의 케이블 규격에서 `부스바 (구리)`를 골라 막대처럼 그릴 수도 있습니다.
5. 차단기를 누르고 **정격 전류 (A)**를 적습니다.
6. **[해석] 탭**에서 결과를 봅니다.

- **검토 항목**
  - 전류가 허용전류를 넘는 전선: `IB > Iz`
  - 차단기 정격이 전선 허용전류보다 큰 곳: `In > Iz` (과부하 때 전선이 먼저 탑니다). 부스바에서 분기 차단기까지 **3 m 이내**이고 중간에 다른 분기가 없는 탭은 끝의 분기 차단기로 검토합니다 (KEC 212.4.2 · IEC 60364-4-43 433.2.2, 표에 `탭 3m`). 단락 보호는 위쪽 차단기가 맡습니다
  - 차단기 정격을 넘는 전류: `IB > In`
  - 전압강하가 허용값을 넘는 부하: 저압 수전은 조명 3% · 기타 5%, 고압 이상 수전은 조명 6% · 기타 8%. 100 m 를 넘는 부분은 m 당 0.005% (0.5% 까지) 더합니다
- 표의 줄이나 문제를 누르면 그림에서 그 전선 · 기기가 강조되고, 화면 밖이면 그쪽으로 이동합니다. 3상 급전선 세 가닥은 한 줄로 묶어 가장 큰 전류로 봅니다.
- **어느 회로에서나 됩니다.** 케이블 규격을 하나도 정하지 않은 회로도 전선마다 전류와 부하 목록이 나옵니다 (릴레이 코일 · 표시등 같은 작은 제어 부하는 접어 둔 표에). 규격이 없는 전선은 `규격을 정하지 않은 전선` 표에 전류 · 위쪽 차단기 정격 · 권장 굵기와 함께 나옵니다. 허용전류 · 전압강하 판정은 규격이 있는 전선에만 합니다.
- **규격 자동 지정**: 규격 없는 전선에 전류와 차단기 정격을 감당하는 가장 가는 굵기를 한 번에 줍니다 (XLPE · B1 기준). 길이는 그림에서 어림한 값 (1칸 = 1 cm, 판넬 안 배선 기준) 이라 **판넬 사이 급전선 · 전동기 케이블은 실제 길이로 고쳐야** 전압강하가 맞습니다.
- **굵기 자동 선정**: 허용전류가 모자라거나 전압강하가 큰 케이블을 필요한 만큼 굵게 바꿉니다. 차단기 정격과 부하는 건드리지 않고, 단상의 L · N 은 같은 굵기로 맞춥니다. `Ctrl+Z` 로 되돌립니다. 문제 문구에도 권장 굵기 (`→ 4 mm² 이상`) 가 붙습니다.
- 케이블 규격을 줄 때 **3상의 나머지 두 가닥에도 함께 적용**됩니다 (같은 두 기기를 잇는 나란한 가닥, 끌 수 있음). 한 가닥만 눌러도 됩니다.
- [해석] 탭을 열어 두면 시뮬레이션을 하지 않아도 그림의 전선마다 가장 클 때의 전류가 적힙니다. 화면을 줄여도 전류 · 선번호 · 분전반 이름은 읽히는 크기로 유지되고, **부품 위에 마우스를 잠깐 올리면** 이름 · 종류 · 정격 · 전류가 카드로 뜹니다.
- **시뮬레이션 중**에는 전류가 흐르는 전선마다 전류가 적히고 (규격이 없는 선도), 부하 상자에 전류 · 단자 전압이, 차단기 옆에 흐르는 전류가 나옵니다. **전선 위에 마우스를 올리면 클램프 미터처럼 그 선의 전류**가 보입니다. 차단기를 내리거나 올리면서 분전반별로 어떻게 달라지는지 볼 수 있습니다.
- 값은 조작 순서대로 돌렸을 때 가장 나쁜 순간 (전류 최대 · 전압 최소) 입니다. 엑셀 CSV 로 저장하고, 보고서에 `전기 해석` 표로 인쇄됩니다.
- 예제: `예제 회로 → 분전반 급전 해석` (메인 분전반 → 부스바 → 급전선 → 분전반 2개. 일부러 넣은 문제 2개를 찾아 굵기를 키워 고쳐 보세요)
- 예제: `예제 회로 → 분전반: 부스바 · 누전차단기 분기` (메인 4P 125 A → 세로 부스바 L1 L2 L3 N → 양옆에 옆으로 놓은 분기 차단기 (3상 3개 · 단상 2개) → 판넬 밖 부하. 실제 분전반처럼 배치한 예)

### 누전 · 지락 시뮬레이션 (접지로 흐르는 전류 · 외함 전압 · 누전차단기)

기기의 절연이 나빠져 충전부 (L) 가 외함에 닿았을 때 (누전) 접지로 얼마가 흐르고, 외함에 몇 V 가 남고, 어느 차단기가 끊는지를 어림합니다.

- **계통 접지 방식**: 전원 단자 속성이나 [해석] 탭 위의 전원 계통 설정에서 고릅니다.
  - **TN-C-S** (기본, 특고압 수전 공장 · 빌딩): 기기 접지선이 변압기 중성점으로 돌아갑니다. 완전 지락은 단락처럼 커서 (220 V ÷ 고장 루프 약 0.4 Ω ≈ 550 A) 일반 차단기가 순시 트립합니다.
  - **TT** (저압 수전 주택 · 작은 공장): 기기를 따로 접지합니다. 지락 전류가 220 V ÷ (기기 접지 Ra 100 Ω + 계통 접지 Rb 10 Ω) ≈ 2 A 뿐이라 일반 차단기는 떨어지지 않고 외함에 약 200 V 가 남습니다. 그래서 **누전차단기 (30 mA)** 가 끊어야 합니다. Ra · Rb 는 바꿀 수 있습니다.
- **외함 접지**: 전동기 · 콘센트 · SMPS 처럼 PE (FG) 단자가 있는 기기는 그 단자가 접지 (PE) 까지 이어졌는지 봅니다. 접지가 안 됐으면 전류는 흐르지 않다가 **사람이 만지면 몸 (약 1000 Ω) 으로 약 220 mA** 가 흐릅니다 (감전). 누전차단기가 있으면 그때 0.03 초 안에 끊습니다. 기호 그림의 기기는 접지를 그리지 않으므로 접지된 것으로 봅니다.
- **누전차단기**: 차단기 속성의 [누전차단기 (ELB)] 와 [정격 감도 전류] (15 · 30 · 100 · 200 · 500 mA). 접지로 샌 전류가 감도 이상이면 0.03 초 뒤 끊습니다. 일반 차단기는 지락 전류가 정격의 10 배 (순시) 이상일 때 0.01 초 뒤 끊습니다. 기기에서 가까운 차단기가 먼저 끊습니다.
- **시뮬레이션에서 누전 일으키기**: 시뮬레이션 중 전동기 · 히터 · 콘센트 · 전등 · SMPS · 솔레노이드를 **Shift+클릭**하면 완전 지락이 생기고, 다시 Shift+클릭하면 없어집니다. 기기 옆에 지락 전류 · 외함 전압이 뜨고, 알림에 끊은 차단기가 나옵니다.
- **조작 순서**: 그 기기를 고르면 동작이 **누전 (절연 불량)** 입니다. [절연 Ω] 은 충전부와 외함 사이 절연 저항 (0 = 완전 지락, 10 kΩ 이면 약 22 mA 로 30 mA 누전차단기는 안 떨어짐), [지속] 은 누전이 이어지는 시간 (0 = 끝까지). 타임차트에 `누전 · 지락` 묶음으로 누전 여부와 지락 전류 (A) 가 나옵니다.
- **[해석] → 누전 · 지락 검토**: 시뮬레이션 없이 기기마다 완전 지락이면 지락 전류 · 외함 전압 · 끊는 차단기와 판정 (끊김 · 위험 · 누설) 을 표로 보여 줍니다. 누전차단기마다 **평상시 누설 전류 합계** (전동기 · 케이블 정전 용량, SMPS 노이즈 필터 어림) 도 내고, 감도의 30% 를 넘으면 이유 없이 떨어질 수 있다고 알립니다.
- **[검사]**: TT 계통인데 누전 때 끊기지 않는 기기 (누전차단기 없음 · 외함 접지 없음) 를 알립니다.
- 예제 **누전 · 지락: 접지와 누전차단기 (TT)**: 절연 10 kΩ → 22 mA 로 안 떨어짐, 완전 지락 → 2 A 로 ELB1 이 0.03 초에 끊음, 고치지 않고 다시 넣으면 또 떨어짐, 콘센트 기기 누전 → ELB2.
- 한계: 값은 어림입니다. 실제 접지 저항 · 절연 저항 · 누설 전류는 접지 저항계 · 절연 저항계 (메거) · 누설 전류계로 재세요. 사람 몸 저항은 젖은 손 · 맨발이면 훨씬 작아져 전류가 커집니다.

### 전력량 · 전기 요금 (kWh · 원)

[해석] 탭 아래 **전력량 · 전기 요금** 에 시뮬레이션에서 부하가 켜져 있던 시간으로 부하마다 전력량과 요금을 계산합니다. 온도 조절처럼 켜졌다 꺼졌다 하는 부하도 실제로 켜진 시간만 셉니다.

- 계산: `전력 (kW) × 켜진 시간 (h) = 전력량 (kWh)`, `전력량 × 단가 (원/kWh) = 전력량 요금`. 예: 5 kW 열풍기를 1시간 돌리면 5 kWh, 182원/kWh 면 910원.
- **단가 (원/kWh)**: 비우면 182원 (2025년 산업용 평균 판매단가 어림). 고지서의 계약 종별 (일반용 · 산업용 · 갑 · 을) 단가로 바꿔 쓰세요.
- **기본요금 (원/kW · 월)** 과 **계약 전력 (kW, 비우면 부하 설비 합)**: 한 달 어림에 `계약 전력 × 기본요금` 이 더해집니다.
- 24시간 타임 스위치가 있는 회로는 하루를 돌리므로 **하루 합계** 와 **한 달 (30일) 어림** (전력량 요금 + 기본요금) 이 나옵니다. 타임 스위치가 없으면 조작 순서 시간 동안의 값과 "1시간 되풀이하면" 값이 나옵니다.
- 부하의 kW 는 부하 · 전동기 속성의 정격 (전동기는 효율로 나눈 입력 전력), 코일 · 램프는 기본값입니다. 표의 줄을 누르면 그 기기가 그림에서 표시됩니다.
- 한계: 계절 · 시간대별 요금, 역률 할인 · 할증, 부가세 · 전력산업기반기금은 넣지 않은 어림입니다.

예제 **열풍기 온도 제어 + 24시간 타이머 (전기 요금)** (`예제 회로 → 제어반 · 릴레이 · 센서`): 단상 220 V → 누전차단기 30 A → 전자접촉기 → **열풍기 5 kW** (외함 PE 접지). 조작은 퓨즈 2 A 뒤에서 **측온저항체 Pt100 → 온도 조절기 (T3S 꼴, 설정 20℃ · 히스테리시스 2℃) → 전자접촉기 코일**. 운전 선택 SS1 은 자동 = **24시간 타이머 (08~18시)** 를 거쳐서만, 수동 = 시간과 상관없이 온도로만, 가운데 = 정지. 조작 순서는 19시에 잔업으로 수동, 20시에 다시 자동 (타이머 시간 밖이라 꺼짐). 작업장은 5℃ 에서 08시에 켜져 25분 만에 20℃, 그 뒤 18 ↔ 20℃ 사이를 오가며 (꺼져 약 10분 · 켜져 약 3분 20초) 하루 약 3시간 15분 켜져 **약 16.3 kWh · 2,970원**, 한 달 약 8만 9천 원입니다.

### 한전 수전부터 변압기까지 계통 해석 (부하율 · 단락 전류)

`실물 배선 → 수전 · 변압기 (계통 해석)` 에 **한전 수전 22.9 kV**, **진공차단기 VCB**, **변압기 3상 (Δ-Y)** 이 있습니다. 한전에서 받은 특고압이 VCB 를 지나 변압기 1차에 세 상이 다 들어가야 변압기 2차에 저압이 나오고, 그 아래 분전반 · 부하가 함께 돌아갑니다. VCB 를 내리면 아래 전체가 정전되고, 한 상이 빠지면 (결상) 2차가 살지 않습니다.

1. 한전 수전점을 맨 위에 놓고 속성에 수전 전압 (kV) 과 **수전점 단락 전류 (kA, 한전 협의값, 모르면 12.5 kA)** 를 적습니다.
2. A B C → VCB 위 단자 (1 3 5), VCB 아래 (2 4 6) → 변압기 1차 H1 H2 H3 로 잇습니다.
3. 변압기 속성에 **용량 (kVA) · 1차 전압 · %임피던스 · X/R** (명판 값) 을 적습니다. 2차 전압은 전원 계통 설정 (기본 380/220 V) 을 따릅니다.
4. 2차 X1 X2 X3 X0 을 저압 메인 4P 차단기로 곧게 내리고 (2칸 간격이 같음), 아래에 부스바와 분기 차단기를 둡니다.
5. 차단기마다 **차단 용량 (kA)** 을 적습니다.

[해석] 탭에 더해지는 것:

- **변압기**: 가장 클 때의 부하 (kVA) 와 부하율 (%), 2차 · 1차 전류, 전압 변동률 (한전 계통 + 변압기 임피던스에서 떨어지는 전압), 2차 단자 단락 전류. 정격을 넘으면 과부하로 알려 줍니다.
- **단락 전류**: 차단기마다 설치점 (전원 쪽 단자) 의 3상 단락 전류를 %임피던스법으로 구합니다 (한전 계통 + 변압기 + 그 점까지 지나온 케이블). 차단 용량보다 크면 문제로 알리고 필요한 표준 차단 용량 (18 · 25 · 35 kA …) 을 권합니다.
- 특고압 쪽 전선은 전류만 적고 저압 허용전류 표로는 검토하지 않습니다. 부하의 전압강하는 변압기 2차 단자부터 잽니다 (고압 수전이면 [해석] 탭의 수전을 `고압 이상 수전` 으로).
- 보고서 · 엑셀 CSV 에 변압기와 단락 전류 표가 들어갑니다.
- 예제: `예제 회로 → 수전 설비: 한전 → 변압기 → 분전반 (계통 해석)` (22.9 kV → VCB → 500 kVA → 저압 메인 800 A → 부스바 → 분기 4개. 일부러 넣은 문제 1개: 조명 누전차단기의 차단 용량이 모자람)

**계산 방법과 한계**

- 허용전류: KS C IEC 60364-5-52 표 B.52.2~B.52.5 (구리, 기중 30℃ · 지중 20℃), 케이블 트레이 (E · F) 는 XLPE 40℃ 기준 표. 주위온도 보정계수 (표 B.52.14) 와 복수회로 감소계수 (표 B.52.17) 를 곱합니다. PVC 는 120 mm² 까지, 지중 (D1 · D2) 은 온도 보정을 하지 않습니다.
- 전압강하: 케이블 한 가닥을 `R = 0.0225 × L / S` Ω, `X = 0.08 mΩ/m` (KS C IEC 60364-5-52 부속서 G 의 값) 로 놓고 회로 전체의 전류를 복소수로 풀어 부하 단자 전압을 구합니다. 규격을 정하지 않은 선과 닫힌 접점은 저항 0 입니다.
- **전원 계통**은 전원 단자를 누르면 나오는 속성 (또는 [해석] 탭) 에서 고릅니다. 그림 전체에 하나이고, 극마다 전압과 위상이 계통에 따라 정해집니다.
  - 3상 4선식 380/220 V (기본): L1 · L2 · L3 는 120° 차이, 두 상 사이 380 V, 상과 N 사이 220 V (Y 결선이라 상전압 = 선간 ÷ √3)
  - 3상 3선식 380 V · 220 V: 중성선이 없습니다. 단상 부하는 두 상 사이 (선간 전압) 에 겁니다. N 단자를 놓으면 전압이 나오지 않고 [검사] 에 표시됩니다
  - 단상 3선식 220/110 V: L1 · L2 가 반대 위상이고 N 이 가운데라 L1-N · L2-N 110 V, L1-L2 220 V. 양쪽 부하가 같으면 N 전류가 0 이 됩니다
  - 단상 2선식 220 V: L · N 만
  - 전압 칸은 3상이면 선간, 단상 3선식이면 L1-L2, 단상 2선식이면 L-N 전압입니다 (예: 3상 3선식 220 V, 3상 4선식 440 V)
- 부하의 **정격 전압**을 적어 두면 다른 전압에 이었을 때 (110 V 기기를 220 V 에, 220 V 기기를 380 V 에) 알려 줍니다. 비우면 이어진 전원에 맞춥니다.
- 단락 전류는 변압기 · 한전 수전점에서 이어진 곳만 계산합니다 (전원 단자만 있으면 전원 임피던스를 모름). 3상 대칭 단락만 보고, 1선 지락 · 전동기 기여분 · 비대칭 (첨두) 값은 계산하지 않습니다.
- **계산하지 않는 것**: 전동기 기동 전류, 차단기 트립 시간 (과부하가 흘러도 스스로 떨어지지 않고 표시만 합니다), 수용률 · 부등률, 고조파, 누전 (ELB), 알루미늄 도체, 부스바 허용전류 표.
- 참고용 계산입니다. 실제 시공 전에는 전기 설계 · 감리 기준으로 확인하세요.

### 결선표 (배선 목록) 보면서 배선하기

회로도 오른쪽 **[결선표]** 탭은 그림의 선을 실제 전선 한 가닥씩, `MCB1 2 → X1 8 (빨강)` 처럼 **단자 → 단자**로 풀어 씁니다. 그림에서 갈라지는 선은 한 나사에 두 가닥을 물리는 것으로 나눠 줍니다.

- 줄을 누르면 그림에서 그 전선이 주황색으로 강조되고 두 단자에 동그라미가 쳐집니다 (화면 밖이면 그쪽으로 이동)
- 배선을 마친 줄은 체크하세요. 체크는 차트 파일에 함께 저장되고, 위쪽 막대로 몇 가닥 남았는지 보입니다
- **선번호**: 같은 전위(같은 넷)는 같은 번호입니다. 단자대 위·아래도 같은 번호라 마크 튜브 번호로 쓰면 됩니다. 전원(L, N)부터 1, 2 … 순서입니다
- 실물 기기의 나사로 들어가는 전선 끝은 기기 그림 위에 다시 그려서, 어느 나사에 물리는지 보입니다
- **그림에 선번호 적기**를 켜면 전선마다 번호표가 그림에 붙습니다. 보고서의 회로도에도 결선표와 같은 번호가 찍힙니다
- **따라 배선하기**: 한 가닥씩 차례로 안내합니다. `완료 → 다음`을 누르면 체크되고 다음 전선으로 넘어가며, 마친 전선만 진하게 · 아직 안 한 전선은 흐리게 보여서 지금 어디까지 했는지 한눈에 보입니다
- 엑셀 CSV 로 저장할 수 있고, 보고서에 체크 칸(☐)과 함께 인쇄됩니다 (`보고서 → 결선표`)

### 회로도를 그려서 타임차트 · 부품 리스트 만들기 (회로도 탭)

맨 앞 `회로도` 탭이 이 프로그램의 시작점입니다. 결선도를 그리면 나머지(타임차트, 부품 리스트, 보고서)는 따라 나옵니다.

1. **예제로 익히기**: 회로도 탭 위쪽 `예제 회로`에서 **자기유지 / 정역 운전(인터록) / 타이머 지연 동작 / 공압 실린더 1사이클 / 전공압 자동 왕복(밸브·근접 센서) / PLC 자기유지 + 타이머** 중 하나를 엽니다. PLC 예제는 PLC 탭에 미쓰비시 프로그램이 함께 들어가고, 그 프로그램을 고치면 회로도 동작도 바뀝니다.
2. **부품 놓기**: 왼쪽 목록(전원, 보호 기기, 조작 스위치, 릴레이·타이머, 출력, 공압)에서 부품을 누르고 그림판을 누르면 놓입니다. `Shift`를 누른 채 놓으면 계속 놓을 수 있고, `R`은 회전, `Delete`는 삭제입니다.
3. **선 긋기**: 부품 단자(작은 점)에서 다른 단자까지 끌면 꺾인 선이 그어집니다. 선 중간에서 끌기 시작하거나 선 끝이 다른 선 중간에 닿으면 T 분기로 이어지고 점이 찍힙니다. 엇갈리기만 한 선은 이어지지 않습니다. 빈 곳에서 시작하려면 `W`(선 긋기 도구)를 쓰세요.
4. **기호로 연동**: 코일 `X1`과 접점 `X1`처럼 기호가 같으면 함께 움직입니다. 타이머 `T1`의 접점은 한시 접점, THR 의 b접점(95-96)은 트립되면 열립니다. 리밋 스위치는 속성에서 실린더 끝(전진단/후진단)에 연결합니다.
5. **시뮬레이션**: `▶ 시뮬레이션`을 누르고 버튼을 마우스로 누릅니다(누르는 동안 ON). 셀렉터·차단기·THR·비상정지는 누를 때마다 바뀝니다 (3단 셀렉터는 누른 쪽으로 돌고, 같은 쪽을 다시 누르면 가운데). 전압이 닿은 선은 극마다 색(L·+24V 빨강, N·0V 파랑, L2 주황, L3 보라)으로 보이고, 코일·램프·전동기 회전(정/역)·실린더 움직임이 그대로 보입니다. 단락, 3상 결상도 알려 줍니다. 속도는 ×0.25 ~ ×4, 일시정지가 됩니다.
6. **조작 순서 → 타임차트**: 오른쪽 `조작 순서`에 "대기 0.5 s → PB1 누름(0.3 s) → 대기 3 s → PB0 누름"처럼 적으면 아래 미리보기에 타임차트가 바로 그려지고 `타임차트` 탭에 반영됩니다. 시뮬레이션에서 직접 눌러 본 뒤 `정지`하면 누른 순서와 시간을 조작 순서로 저장할 수도 있습니다. 메모를 적으면 차트의 공정 스텝 이름이 되고, 타이머 지연은 치수선으로 자동 표시됩니다.
7. **부품 리스트**: `부품 리스트`에 기호마다 품명·설명·사양·접점 수(예: 전자접촉기 주접점 3P, 보조 2a1b)가 나오고, 같은 품명·사양끼리 수량을 모은 표가 함께 나옵니다. `엑셀 CSV 저장`으로 받거나 보고서에 넣어 인쇄합니다.
8. **검사**: 코일이 없는 접점, 같은 기호의 코일 두 개, 이어지지 않은 단자, 전원 없음 같은 실수를 `검사`에서 알려 줍니다.

> 차트가 손으로 그린 것이면 회로를 고쳐도 덮어쓰지 않습니다. 이때는 `타임차트에 적용`을 눌러야 바뀝니다. 같은 기호의 신호는 이름·색·화살표를 유지하고 파형만 바뀝니다. 새 회로는 `+ 차트 추가 → 회로도로 새 차트`로 시작하세요.

### 내 설비의 타임차트를 처음부터 만들기 (동작 순서 탭)

실무에서 타임차트는 파형부터 그리지 않습니다. 설계 순서가 있고, 타임차트는 그 결과물입니다.

| 순서 | 하는 일 | 왜 필요한가 |
|---|---|---|
| ① 설비 사양 | 어떤 설비인지, 한 사이클을 몇 초 안에 끝내야 하는지(목표 사이클 타임, 택트 타임) 정합니다. | 목표가 있어야 나중에 "시간 안에 들어오는가"를 판단합니다. |
| ② 동작 기기 | 움직이는 것(실린더, 모터, 흡착·척)을 적고, 한쪽 끝에서 반대쪽 끝까지 걸리는 **동작 시간**을 적습니다. | 차트의 막대 길이와 경사선이 이 시간입니다. 모르면 0.5초로 두고 시운전 뒤 실측값으로 고칩니다. |
| ③ I/O 목록 | 기기마다 PLC 가 켜는 **출력**(솔레노이드 SOL, 모터)과 PLC 가 읽는 **입력**(시작 버튼, 끝 위치 센서)을 정하고 주소(X0, Y0 / P00000 / I0.0)를 붙입니다. | 제어 설계(PLC 프로그램, 배선도)와 같은 이름·주소를 쓰기 위해서입니다. |
| ④ 동작 순서 | 한 사이클 동안 무엇이 먼저 움직이고, 무엇이 동시에 움직여도 되는지 정합니다. 보통은 앞 동작이 끝났다는 센서를 확인한 뒤 다음 동작을 시작합니다. | 동시에 움직여도 부딪히지 않는 동작을 겹치면 사이클 타임이 줄어듭니다. 마지막에는 모든 기기가 원위치로 돌아와야 다음 사이클을 시작합니다. |
| ⑤ 타임차트 · 검토 | 위 내용으로 차트를 그리고, 목표 사이클 타임 안에 들어오는지, 동시에 켜지면 안 되는 출력(전진 SOL 과 후진 SOL)이 겹치지 않는지 확인한 뒤 작성·검토·승인합니다. | 이 차트가 PLC 프로그램 작성과 시운전의 기준이 됩니다. |

위쪽 **동작 순서** 탭이 이 순서를 한 페이지에 위에서 아래로 그대로 놓았습니다. 처음 열면 **예시로 시작하기**(클램프 → 프레스) 또는 **빈 표로 시작하기**를 고릅니다(`파일 → 새 차트: 동작 순서표로 만들기`와 같음).

1. **① 설비**: 설비 이름, 차트 제목, 도면 번호, 작성자, 목표 사이클 타임(초). 이 칸은 차트 제목과 보고서 표제란에 바로 들어갑니다.
2. **② 동작 기기**: 이름, 종류, 가는·돌아오는 동작 이름, 가는·돌아오는 시간(초), 끝 센서 유무를 표에 적습니다. 종류는 네 가지입니다.
   - 실린더 (더블 SOL): 전진 SOL 과 후진 SOL 두 개. 신호를 끊어도 그 자리에 머뭅니다. 차트에는 움직이는 동안만 SOL 이 켜집니다.
   - 실린더 (싱글 SOL): SOL 하나. 켜 두는 동안 전진해 있고, 끄면 스프링으로 돌아옵니다.
   - 모터: 운전 출력 하나. 기동부터 정지까지 켜져 있습니다.
   - 흡착 · 척: SOL 하나와 흡착(잡힘) 확인 센서.
3. **③ I/O 목록**: 기기에서 입력·출력을 자동으로 뽑아 번호를 매깁니다. 주소 방식(미쓰비시 8진수 X0·Y0 / LS P00000·P00040 / 지멘스 I0.0·Q0.0 / 주소 없이)을 고르고, 실제 배선과 다른 주소나 이름만 고칩니다. `PLC 탭 코멘트로 보내기`를 누르면 이 이름들이 PLC 탭의 디바이스 코멘트에 들어가서, 나중에 PLC 프로그램을 시뮬레이션할 때 같은 이름으로 보입니다.
4. **④ 동작 순서**: 한 줄에 기기와 동작 하나(예: 클램프 · 전진). 시작 칸은 **앞 동작이 끝난 뒤** 또는 **앞 동작과 동시에**. 끝에 `+0.2`처럼 초를 붙이면 그만큼 늦게 시작합니다(센서 확인 후 안정화 0.2초, 실린더가 출발하고 0.3초 뒤 블로우 등). 가공·가압처럼 기다리기만 할 때는 기기 칸에 `대기`, 동작 칸에 무엇을 기다리는지(가공)를 적습니다. 오른쪽 **시간 흐름** 막대가 바로 바뀝니다. 이미 그 위치인 기기를 또 움직이거나, 사이클이 끝났는데 원위치로 돌아오지 않은 기기가 있으면 "검토할 점"으로 알려 줍니다.
5. **⑤ 확인**: 예상 사이클 타임, 목표 대비 OK/NG 와 여유, 가장 긴 스텝, **실제 차트 미리보기**가 표를 고칠 때마다 바뀝니다. 괜찮으면 **차트에 적용**을 누릅니다.

**표는 엑셀처럼 씁니다**

| 조작 | 하는 일 |
|---|---|
| 칸을 누르고 바로 입력 | 그 칸 값을 바꿈 (한글 입력 그대로) |
| Enter / Tab / 방향키 | 아래 / 오른쪽 / 그 방향 칸으로 이동 |
| F2, 두 번 클릭 | 지금 값을 고치기 |
| 마지막 빈 줄에 입력 | 줄이 늘어남 |
| Ctrl+C / Ctrl+V | 엑셀·구글 시트와 여러 칸 복사·붙여넣기, 한 칸 값을 여러 칸에 붙이면 모두 채움 |
| 마우스로 끌기, Shift+방향키 | 범위 선택 |
| 줄 번호 누르고 Delete, Ctrl+- | 줄 삭제 |
| Alt+↑ / Alt+↓, Ctrl+D | 줄 위아래로 옮기기, 줄 복제 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 하기 |

- ④ 에 ② 에 없는 기기 이름을 적으면 기기가 자동으로 생깁니다(더블 SOL 실린더). 처음 적은 동작 이름(예: `하강`)이 그 기기의 가는 동작이 되고 반대 동작(`상승`)도 채워집니다. 같은 기기 이름만 한 번 더 적으면 반대 동작이 됩니다.
- **엑셀 동작 순서표 붙여넣기**: 엑셀에서 표를 복사해 ④ 의 첫 칸을 누르고 `Ctrl+V` 하거나, `엑셀 표 붙여넣기…` 버튼을 누릅니다. 첫 줄이 제목(`기기`, `동작`, `시간`, `시작` 같은 말이 들어간 칸)이면 제목으로 칸을 맞추고, `시간(ms)` 처럼 ms 라고 적힌 칸은 ms 로 읽습니다. 제목 줄이 없으면 기기 · 동작 · 시간 · 시작 순서로 읽고, 맨 앞 칸이 순서 번호(1, 2, S10 …)면 건너뜁니다. `클램프 전진`, `가공 대기`처럼 한 칸에 적어도 나눠서 읽습니다.
- **엑셀 I/O 리스트 붙여넣기**: ③ 표에 제목 줄(`주소`, `이름`/`코멘트`)과 함께 붙여 넣으면 이름이 같은 I/O 를 찾아 주소를 넣습니다. 제목 줄 없이 붙이면 누른 칸부터 차례로 들어갑니다.
- `엑셀로 복사` 버튼은 기기 표, I/O 목록, 동작 순서표를 엑셀에 바로 붙일 수 있게 복사합니다.

고친 내용은 바로 파일에 들어가고(자동 백업, `Ctrl+Z` 가능), **차트는 `차트에 적용`을 눌렀을 때만 다시 만듭니다.** 적용하지 않은 변경이 있으면 위쪽 `동작 순서` 탭에 주황 점이 붙습니다. 적용한 뒤 차트에서 파형·화살표·주석을 손으로 고쳤다면 다시 적용하기 전에 한 번 묻습니다(적용한 뒤에도 `Ctrl+Z`로 되돌릴 수 있음). 표제란(제목·회사·검토·승인), 보고서 설정, PLC 설정은 다시 적용해도 그대로입니다.

만들어지는 차트에는 이런 것이 들어갑니다.
- 기기별 그룹: 출력(SOL, 모터) 파형, 실린더 동작선(경사 = 동작 시간), 끝 위치 센서 파형(원위치 센서는 떠나는 순간 꺼지고 돌아오면 켜짐)
- 대기 타이머 행, 공정 스텝 띠(S10, S20 …), "센서 확인 → 다음 동작" 화살표, 사이클 완료 표시
- 검토 규칙: 목표 사이클 타임, 더블 SOL 실린더마다 "전진/후진 SOL 동시 ON 금지". 결과는 아래 `타이밍 규칙 검증` 탭과 보고서에 나옵니다.
- 보고서에는 **동작 순서표(설계)**가 따로 실립니다: 스텝, 기기, 동작, 시간, 시작 조건, 시각, 출력 주소(예: `Y0 ON`), 완료 확인 센서(예: `X1`).

### 설비 하나를 파일 하나로 (차트 여러 장)

한 설비에는 보통 자동 운전 사이클, 원점 복귀, 유닛별 동작처럼 차트가 여러 장 있습니다. 위쪽 **차트 탭**(엑셀의 시트처럼)에서 한 파일에 모아 관리합니다.

- `+ 차트 추가`: 동작 순서표로 새 차트 / 빈 차트 / 지금 차트 복제 / 템플릿. 새 차트는 회사·설비·도면 번호·작성·검토·승인을 그대로 이어 받습니다.
- 탭을 누르면 그 차트로, 두 번 누르면 이름 바꾸기(자동으로 붙은 제목이면 제목도 함께 바뀜). `▾` 메뉴로 복제, 왼쪽/오른쪽으로 옮기기, 삭제. `Ctrl+PgUp` / `Ctrl+PgDn`으로 넘깁니다.
- 차트마다 동작 순서표, PLC 설정, 표제란, 실행 취소 기록이 따로 있습니다.
- 왼쪽 폴더 아이콘 옆 이름이 **설비 이름**이고, 저장할 때 파일 이름이 됩니다.
- 차트가 한 장뿐이면 예전과 똑같은 형식으로 저장되어 이전 버전에서도 열립니다.

### 인쇄: 한 장 · 세로 · 흑백

`보고서` 탭(또는 `Ctrl+P`)에서 고릅니다.

- **출력 방식 → 한 장으로**: 제목, 사이클 타임·목표·규칙 결과, **전체 타임차트**, 공정 스텝 표를 한 장에 맞춰 넣습니다. 차트는 행 높이를 늘리거나 줄여 페이지에 맞추므로 글자가 작아지지 않습니다. 설비 옆에 붙여 두거나 회의 자료로 쓰기 좋습니다.
- **출력 방식 → 여러 장 보고서**: 표지·요약, 타임차트, 동작 순서표(설계), 신호(I/O) 목록, 공정 스텝, 입출력 변화 순서, 규칙 검증, 인터록·주석을 싣습니다. 짧은 표는 한 장에 모으고, 긴 표는 제목 줄을 되풀이하며 다음 장으로 잇습니다.
- **용지 · 방향**: A4/A3, 가로/세로. 세로 용지에서는 차트 행을 높여 빈 곳을 채우고, 표제란 칸 폭도 세로에 맞춥니다.
- **흑백 프린터용**: 선은 검정으로 굵게, ON 구간은 색 대신 무늬로 구분합니다(출력 = 진한 칠, 입력·센서 = 빗금, 실린더 동작·타이머 = 옅은 칠). 차트 아래에 범례가 붙습니다.
- **인쇄 범위 → 설비 전체**: 차트가 여러 장이면 맨 앞에 목차(차트, 제목, 사이클 타임, 스텝 수, 규칙 결과, 페이지)를 붙이고 모든 차트를 차례로 싣습니다. "한 장으로"와 함께 쓰면 차트마다 한 장씩입니다.
- 인쇄 창의 배율은 기본값(100%)으로 두세요. 용지와 방향은 여기서 고른 대로 맞춰집니다. PDF 로 남기려면 프린터를 "PDF로 저장"으로 고릅니다.

### 연습 문제: 직접 그려 보고 채점받기

타임차트는 읽을 줄 아는 것과 직접 그릴 줄 아는 것이 다릅니다. `배우기 → 연습 문제` (또는 시작 화면, 도움말 `?`)에서 문제를 골라 직접 그려 보고 채점받을 수 있습니다.

**푸는 방법**
1. 문제를 고르면 차트가 연습용으로 바뀝니다. 위쪽 **① 주어진 입력**(버튼을 누른 시각 등)은 그대로 두고, 아래쪽 **② 그려야 할 신호**를 그립니다.
2. 아래 **연습 문제** 칸에 문제, 배우는 것, 주어진 조건, 그릴 것이 적혀 있습니다. PLC 문제에는 래더 그림과 니모닉(미쓰비시)이 함께 나옵니다.
3. 연필(그리기) 도구로 그립니다. `Shift` 를 누르고 끌면 ON, `Alt` 를 누르고 끌면 OFF 로 칠해집니다. 눈금(0.1초)에 자동으로 붙습니다.
4. **채점하기**를 누르면 신호마다 맞았는지 알려 줍니다. 틀렸으면 "2초에 OFF 되어야 하는데 2.5초에 OFF 되었습니다", "ON 구간이 2번 있어야 하는데 1번 그렸습니다", "시작할 때(0초) ON 이어야 합니다"처럼 어디가 다른지 구체적으로 알려 줍니다. 시각은 눈금 한 칸(0.1초) 안이면 맞은 것으로 봅니다.
5. 막히면 **힌트**를 하나씩 열어 봅니다(문제마다 2~3개). **정답 보기**로 정답 차트를 보고 **내 답 보기**로 돌아올 수 있습니다. **해설**에는 몇 초에 무엇이 왜 일어나는지 단계별 설명과 실무 메모가 있습니다.
6. 맞힌 문제는 문제 목록에 ✓ 와 점수가 남습니다(이 브라우저에만 저장). **연습 끝내기**를 누르면 연습 전 차트로 돌아옵니다.

**PLC 읽기: 프로그램을 보고 출력 파형 그리기** (정답은 내장 PLC 시뮬레이터로 계산)

## 4. LS XG5000 사용자: 니모닉(IL) PDF로 차트 만들기

XG5000은 니모닉을 텍스트나 CSV로 내보내는 기능이 없고 **인쇄(PDF)** 만 됩니다. 이 프로그램은 그 PDF를 그대로 읽습니다.

1. XG5000에서 프로그램을 열고 **니모닉(IL) 보기** 상태에서 인쇄합니다.
2. 프린터를 **"Microsoft Print to PDF"** 로 골라 PDF로 저장합니다.
3. TimeChart Studio → `PLC 시뮬레이션` 탭 → **`파일 열기 (PDF 가능)`** → 저장한 PDF를 고릅니다. PDF 파일을 창에 끌어다 놓아도 됩니다.
   - 페이지 머리말, 표 제목, 렁 설명문, 페이지 번호는 자동으로 걸러내고 명령어와 오퍼랜드만 읽습니다.
   - 줄 끝의 설명문(예: `LOAD P00000 시작 버튼`)은 신호 이름으로 씁니다.
   - 가운데 칸 위에 "명령 N개, 디바이스 M개"가 나오고, 읽지 못한 명령이 있으면 줄 번호와 함께 표시합니다.
4. **입력 자극**: 시작 버튼 같은 입력에 "펄스"를 고르고 시간(예: `100-300`, 단위 ms)을 넣습니다. `자동 설정` 버튼을 누르면 "시작"이라는 이름이 붙은 입력에 자동으로 넣어 줍니다.
5. **설비 모델**: `+ 실린더`를 눌러 "전진 출력 = P00040, 전진단 센서 = P00001, 후진단 센서 = P00002, 전진 시간 0.4s"처럼 적습니다. 그러면 솔레노이드가 켜진 뒤 그 시간이 지나 센서가 알아서 켜지므로, 사이클이 끝까지 진행됩니다.
   - 크레인 주행·횡행·권상, 컨베이어처럼 **위치가 움직이는 축**은 `+ 위치 축`을 씁니다. 정/역 출력, 속도(단위/초), 속도 선택 출력(저속·고속), 엔코더 카운터(예: C0251), 리밋 스위치의 위치 구간(예: UP.END = 0~9900 에서 ON)을 적으면, 출력이 켜진 동안 위치가 움직이고 엔코더 값과 리밋 스위치가 저절로 바뀝니다. 차트에는 위치가 경사선(아날로그)으로 그려집니다.
6. **타이머 단위**: XGK 기본 파라미터의 타이머 단위(보통 100ms)와 `타이머 기본 단위`를 맞춥니다. `TON T0000 5` → 100ms × 5 = 0.5초입니다.
7. `▶ 시뮬레이션 → 타임차트 생성`을 누릅니다.

### 실제 I/O가 M 릴레이로 매핑된 프로그램 (공정이 안 보일 때)

많은 프로그램이 앞부분에서 `LOAD P00019 → OUT M0062C`처럼 **실제 입력(P)을 M 릴레이로 옮겨 놓고**, 나머지 로직은 전부 M 으로만 짭니다. 출력도 `LOAD M00004 → OUT P00021`처럼 M 을 거쳐 내보냅니다. 그러면 로직만 봐서는 "어느 버튼, 어느 모터인지" 알기 어렵습니다. 이 프로그램은 이 매핑을 **자동으로 추적**합니다.

- **자동 추적**: 단순 복사 렁(`LOAD P → OUT M`), 반전 복사(`LOAD NOT P`), 항상 ON 조건을 거친 복사(예: `AND A크레인선택`, F00099)와 여러 단계 사슬(P00019 → M0062C → M00440)을 끝까지 따라가 원본 I/O 를 찾습니다. 자기유지나 실제 조건이 붙은 렁은 매핑으로 보지 않습니다.
- **디바이스 목록**: `M00440  = P00019 UP`, `M00004  → P00021`처럼 옆에 실제 I/O 가 표시됩니다. 설명이 없는 M 은 원본 I/O 의 설명을 물려받습니다. 검색 칸에 `P00019`를 치면 그 입력을 받아 쓰는 M 릴레이까지 찾아집니다.
- **I/O 매핑표**: 디바이스 목록 아래 `I/O 매핑표`를 펼치면 "실제 I/O ↔ 프로그램에서 쓰는 M 릴레이" 표가 나옵니다.
- **실제 I/O로 바꾸기**: 차트 행 순서 옆 버튼을 누르면, 표시 목록의 매핑 릴레이를 실제 입출력(P)으로 바꿔 줍니다. `자동 설정`도 매핑 릴레이 대신 실제 I/O 를 고릅니다.
- **공정이 보이게**: `공정 스텝 디바이스`를 **"출력 조합으로 자동"** 으로 두면, "지금 어떤 출력이 켜져 있나"가 바뀔 때마다 공정 스텝을 나눕니다 (예: `UP → UP + 저속 → LEFT → BACK우 → 대기 → DOWN`). 전원 MC처럼 거의 항상 켜진 출력, 램프·부저, 깜빡이는 출력은 빼고, 설비 모델의 동작 출력 이름을 먼저 씁니다. 스텝 레지스터가 없는 LS 프로그램은 이것이 기본값입니다.
- **동작 순서표**: 차트 아래 `동작 순서표` 탭에 "몇 초에 무엇이 켜지고 꺼졌는지"가 시간 순으로 나오고(직전 변화와의 간격, 속한 공정 스텝 포함), 행을 누르면 그 시각으로 이동합니다. 보고서에도 같은 표가 들어갑니다.

알아 두세요
- 글자를 고를 수 없는 **스캔(이미지) PDF**는 읽지 못합니다. 반드시 XG5000에서 직접 PDF로 인쇄하세요.
- PDF에서 복사한 텍스트를 편집 칸에 붙여넣어도 됩니다. 칸이 한 줄씩 쪼개져 붙어도 읽습니다.
- 디바이스 설명문(변수/설명문 목록)도 PDF로 인쇄해서 `디바이스 코멘트 → CSV / PDF`로 열 수 있습니다.
- 지원: **XGK / XGB** 니모닉(LOAD, AND NOT, OR LOAD, MPUSH, OUT, SET/RST, TON/TOFF/TMR, CTU/CTD, MOV/INC/ADD, 비교 LOAD= 등). **XGI/XGR**의 IEC식 IL(LD, ST …)은 아직 지원하지 않습니다.

## 8. 자주 묻는 질문

- **인터넷이 없어도 되나요?** 오프라인 파일로 받으면 됩니다. 파일 하나에 모든 기능이 들어 있습니다.
- **무료인가요? 회원가입이 필요한가요?** 무료이고, 가입이나 로그인 없이 씁니다.
- **회사 PLC 프로그램이 외부로 나가지 않나요?** 나가지 않습니다. 파일을 여는 것도, 계산도 모두 내 PC 브라우저 안에서만 합니다.
- **엑셀로 옮길 수 있나요?** `내보내기 → 엑셀 CSV`(변화 시점표, 신호 목록, 스텝표)를 쓰거나, `이미지 복사` 후 엑셀·파워포인트·한글에 붙여넣으세요.
- **시뮬레이션 결과를 그대로 믿어도 되나요?** 설계 검토용입니다. 실제 설비의 응답 시간은 설비 모델에 넣은 값에 따라 달라집니다. 실측 로그(CSV)를 가져와 비교할 수 있습니다.
- **맥이나 태블릿, 휴대폰에서도 되나요?** 크롬·엣지에서 확인했습니다. 맥에서도 크롬으로 열면 됩니다. 휴대폰은 보기와 간단한 수정용이고, 편집은 마우스가 있는 PC가 편합니다.
- **안 되는 게 있거나 원하는 기능이 있어요.** [Issues](https://github.com/mioon1402/TimeChartForAutomation/issues)에 남겨 주세요. 가능하면 PLC 종류와 화면 캡처를 함께 적어 주세요. 회사 프로그램 원본은 올리지 마세요.

## 9. 기능 상세

### 회로도 시뮬레이션
- 부품: 전원(L·N, +24V·0V, 3상 L1·L2·L3, SMPS AC→DC 24V), 배선용 차단기 1P·3P, 퓨즈 1P·3P, 열동형 과부하 계전기(THR, 트립/복귀), 푸시버튼 a·b(색), 셀렉터 a·b, 비상정지, 리밋 스위치 a·b, 리드·플로트·압력·온도 스위치, 근접 센서(유도형·정전용량형)·광전 센서(3선식 PNP/NPN), 릴레이·전자접촉기 코일, 보조 a·b접점, MC 주접점 3P, 타이머(ON/OFF 딜레이, 한시 접점), 플리커 릴레이, 파일럿 램프(5색), 부저, 3상 전동기, 단상·직류 전동기, 솔레노이드, 공압원, 에어 서비스 유닛(FRL), 3/2·5/2(편솔·양솔)·5/3(올포트 블록) 밸브, 속도 제어 밸브, 공압 실린더(단동 / 복동), PLC 블록, 글자
- 3선식 센서: 갈색(+24V)·파랑(0V)에 전원을 이어야 동작합니다. PNP 는 감지하면 검정선이 +24V, NPN 은 0V 가 됩니다. 실린더 끝(전진단·후진단)에 연결하거나 시뮬레이션에서 눌러서 감지시킵니다
- 공압: 공압원 → FRL → 밸브 1번 포트, 밸브 4(A)·2(B) → 실린더 헤드 쪽·로드 쪽 포트를 배관(선 긋기와 같음, 하늘색)으로 잇습니다. 밸브는 같은 기호의 솔레노이드(전기 회로의 SOL1 등)로 움직이고, 압력이 들어간 배관은 진하게 보입니다. 로드 쪽 배관이 없으면 단동(스프링 복귀), 5/3 밸브 가운데에서는 실린더가 그 자리에 멈춥니다. 속도 제어 밸브를 배기되는 쪽 배관에 달면 그 방향이 느려집니다(미터 아웃). 배관 없이 실린더 속성에서 솔레노이드를 바로 정하는 간단한 방식도 그대로 됩니다
- PLC 블록: 입력 8개(위)와 공통 C · 릴레이 출력 8개(아래). 입력 단자에 +24V·L 이 닿으면 ON, 출력은 C ↔ Q 접점. 첫 주소(X0/Y0, P00000/P00040, I0.0/Q0.0, %IX0.0/%QX0.0)에서 차례로 번호가 붙고, PLC 시뮬레이션 탭의 프로그램을 스캔 타임마다 실행합니다. 버튼 → PLC → 램프·MC·솔레노이드까지 한 회로로 움직이고, 타임차트에 PLC 입출력 행(디바이스 코멘트 이름)이 함께 나옵니다
- 계산: 닫힌 접점으로 이어진 선을 묶고, 부하의 두 단자가 같은 계통의 다른 극(+24V↔0V, L↔N, L1↔L2 …)에 닿으면 동작. 3상 전동기는 상 순서로 정/역을 정하고 두 상만 닿으면 결상. 한 선에 서로 다른 극이 닿으면 단락
- 시간: 타이머 만료, 실린더 도착·끝 센서 벗어남(스트로크 3%)을 사건으로 계산해서 시간이 정확합니다(스캔 간격 오차 없음)
- 조작 순서에서 같은 시각의 조작 (대기 0) 은 **동시에** 바뀝니다. 그래서 이중 인터록 (버튼 b접점) 회로에서 정 · 역 버튼을 함께 누르면 어느 쪽도 붙지 않습니다. 접촉기 b접점만 있는 인터록은 앞 렁이 이기고, 계속 켜졌다 꺼지는 회로는 발진으로 알려 줍니다
- **릴레이 동작 시간**: 기본은 코일이 바뀌면 접점이 바로 바뀝니다 (0 ms, 이상적). 그래서 자기 접점으로 자기를 끊는 회로 (예: OFF 딜레이 타이머의 한시 b접점이 자기 앞 릴레이를 끊는 고리) 는 릴레이가 "같은 순간에 붙었다 떨어져" 차트에 안 보이고, 그때는 **0초 펄스** 경고가 나옵니다. `조작 순서 → 릴레이 동작 시간 (ms)` 에 실제 값 (릴레이 · 전자접촉기 10~30 ms) 을 넣으면 코일 · 타이머가 그만큼 늦게 붙고 떨어져서, 출력이 아주 짧게 끊기는 모습까지 타임차트에 나옵니다 (Y-Δ 전환 · 정역 전환 사이의 짧은 공백도 보임). 시작할 때는 전원이 이미 들어와 자리 잡은 상태에서 출발합니다
  - 동작 시간을 넣으면 접촉기 b접점만으로 인터록한 정 · 역 버튼을 동시에 눌렀을 때 **두 접촉기가 함께 붙어 단락**이 나는 것도 보입니다 (그래서 버튼 b접점 인터록 · 기계적 인터록을 같이 씀)
  - 자기 b접점으로 자기 코일을 끊는 회로는 동작 시간 두 배 주기로 붙었다 떨어지며 **채터링** 경고가 나옵니다
- 회로·조작 순서는 차트(.tchart)에 함께 저장되고, 실행 취소(Ctrl+Z)·자동 백업이 됩니다. 회로도는 PNG·SVG 로 내보낼 수 있습니다

### 래더(LD)를 그려서 PLC 블록으로 돌리기
PLC 시뮬레이션 탭에서 PLC 종류를 **미쓰비시** 또는 **LS** 로 두고 위의 **[래더 (LD)]** 를 누르면 래더 편집기가 열립니다. 이미 있는 니모닉 프로그램은 그대로 래더 그림으로 바뀝니다.

1. 칸을 고르고 **F3** a접점 · **F4** b접점 · **Shift+F3 / F4** 상승 · 하강 접점 · **F5** 가로선 · **F9** 코일 · **Shift+F9** SET · **F10** 응용 명령(MOV 등)을 놓습니다. 놓자마자 디바이스 이름(X0, P00000 …)을 치고 Enter 를 누르면 오른쪽 칸으로 넘어갑니다 (XG5000 · GX Works 와 같은 손놀림).
2. 병렬(OR)은 **[줄 추가 (병렬)]** 로 아래 줄을 만들고 **F6** 세로선(칸 오른쪽에서 아래로) · **Shift+F6** 세로선(칸 왼쪽에서 아래로)으로 잇습니다. 자기유지는 X0 아래 줄에 Y0 a접점을 놓고 X0 오른쪽에 F6 을 누르면 됩니다.
3. 타이머 · 카운터는 [TON] · [CTU] 를 놓고 설정값(100 ms 단위 · 횟수)을 적습니다. LS 는 OFF 딜레이(TOFF)도 됩니다.
4. 편집 칸에 **디바이스 설명**(코멘트)과 렁마다 **렁 설명**(설명문)을 적을 수 있습니다.
5. 그린 래더는 바로 니모닉으로 바뀝니다 (아래 [니모닉] 을 펼쳐 보기). 시뮬레이션 · 타임차트 · 회로도의 PLC 블록이 모두 이 니모닉을 실행합니다. 잘못 그린 렁(디바이스 빠짐, 출력 없음, 설정값 없음)은 렁 번호와 함께 빨갛게 알려 줍니다.

- STL · 점프 · MC 처럼 래더 칸으로 그리기 어려운 렁은 니모닉 그대로 한 렁으로 두고, 그 렁도 그대로 실행됩니다.
- **회로도에서 실시간 모니터**: 회로도 탭에 PLC 블록이 있는 회로를 [시뮬레이션] 하면 오른쪽 [속성] 칸에 래더 모니터가 나와서 켜진 접점 · 코일 · 타이머가 초록으로 칠해집니다 (예제 회로 → 기호 회로 → **PLC 자기유지 + 타이머**).

### PLC 시뮬레이션
- 스캔 단위 실행: 타이머(100ms/10ms, FX 번호별 단위), 카운터, 상승/하강 에지, SET/RST, MPS/MRD/MPP, 비교 접점, MOV/INC/ADD, **미쓰비시 STL 스텝 래더**, MC/MCR, 점프를 처리합니다.
- 설비 모델: 실린더(싱글/더블 솔레노이드, 전진·후진 시간), 지연 응답(ON/OFF 지연, 반전), 위치 축(정/역 출력, 속도 선택, 엔코더 카운터, 위치 구간 리밋 스위치, 프로그램의 엔코더 리셋 반영)
- 공정 스텝 자동 생성: 스텝 레지스터(D0, CASE Step), STL S 릴레이, 켜진 출력 조합
- I/O 매핑 추적: M 릴레이 ↔ 실제 I/O (입력 매핑·출력 매핑, 반전, 여러 단계 사슬)
- 스캔마다 바뀌는 워드(엔코더 등)는 칸 대신 아날로그 선으로 표시
- 코드를 고쳐 다시 시뮬레이션해도, 직접 고친 신호 이름·색·화살표·규칙은 주소 기준으로 유지됩니다.

## English

**TimeChart Studio** is a free, browser-based timing-chart tool for automated machines.

- **Use it now:** https://mioon1402.github.io/TimeChartForAutomation/ (no install, no sign-up). For offline PCs, download [TimeChartStudio.html](https://mioon1402.github.io/TimeChartForAutomation/TimeChartStudio.html) and double-click it.
- **Circuit tab (like CADe SIMU):** draw relay, contactor, timer, overload, motor and pneumatic circuits on a grid and run them by clicking buttons; live wires are coloured by pole, motors spin forward/reverse, cylinders move, shorts and open phases are flagged. Write the operator actions (or record them while simulating) and the timing chart is generated; the parts list (tags, item, spec, contacts used, quantities) comes straight from the drawing and prints in the report.
- **Draw** bit, word, analog and clock signals; sloped actuator motion; cause-and-effect arrows; time dimensions; process steps.
- **Earth faults**: inject an insulation fault on a motor, outlet or heater (Shift+click while simulating, or an operation step with insulation resistance) and see the earth current, the frame voltage and which breaker or RCD trips, for TN-C-S or TT earthing (Ra/Rb). The Analysis tab lists every device's fault current, touch voltage and protective device, and the standing leakage on each RCD.
- **PLC panel devices**: a real-wiring PLC (16 in / 16 relay out with supply, input COM and output commons; restarts after a power loss) and an HMI touch panel whose buttons and lamps read and write PLC devices; the wiring check warns about AC on DC inputs, unfused output commons and contactor coils switched straight from PLC outputs. Example: a two-pump panel with local / HMI operation, interposing relays and a hardwired E-stop.
- **Ladder (LD) editor** for Mitsubishi and LS programs with GX Works / XG5000-style keys (F3 NO, F4 NC, F5 line, F6 vertical, F9 coil); existing mnemonics open as ladder, the drawing compiles to mnemonics, and a live ladder monitor shows ON contacts while the circuit with the PLC block runs.
- **Generate charts from PLC programs** by scan simulation: Mitsubishi GX Works (IL/CSV), LS XG5000 (IL, including printed IL PDFs), Siemens STL, IEC 61131-3 ST/SCL. Equipment models (cylinders, delays, moving axes with encoders and limit switches) respond to outputs so the whole cycle runs.
- **Sequence tab** following real design practice on one page: machine spec → moving devices and motion times → I/O list with PLC addresses → sequence (after / together with previous) → live preview with cycle time and interlock checks. The tables work like a spreadsheet (type, arrow keys, Ctrl+C/V with Excel); paste an Excel sequence table or I/O list and columns are matched by their headers.
- **One machine, one file:** keep every chart of a machine (auto cycle, homing, each unit) as tabs in one `.tchart` file, and print them together with a contents page.
- **Printing:** one-page summary (whole chart fitted to the sheet), portrait or landscape, black-and-white patterns instead of colors, and packed multi-page reports.
- **Practice mode** (Learn → Practice): 15 problems. Read a short PLC program (self-holding, timers, pulses, interlocks, counters, flicker, sequential start, off-delay, timeout alarm) or a machine description and draw the outputs and sensors yourself; each signal is graded with a specific message, with hints, the answer and a step-by-step explanation.
- **Built-in tutorials** (Help `?` or the start screen) point at each control and advance as you try it.
- **Understand the process:** relays that just copy real I/O are traced back to the physical input/output, steps are built from which outputs are ON, and a sequence-of-events table lists every change in order.
- **Check and report:** response time, interlock, pulse width and cycle-time rules; printable reports with a title block; PNG/SVG, Excel CSV, WaveDrom and a text format.
- Files you open are processed only in your browser and never uploaded. The UI switches between Korean and English (top-right `EN` button).
- Bugs and ideas: [Issues](https://github.com/mioon1402/TimeChartForAutomation/issues).

- 회로도는 전압·전류 값을 계산하지 않고 "어느 극에 닿았나"로 판단합니다. 부하를 직렬로 이은 회로, 다이오드·아날로그 부품은 아직 없습니다. PLC 블록은 한 회로에 여러 개 놓아도 프로그램은 PLC 탭의 하나를 함께 씁니다.
- 래더는 미쓰비시 · LS 니모닉으로만 그릴 수 있습니다 (지멘스 STL · ST 는 글자로 편집). PLC 소프트웨어의 프로젝트 파일(.gxw · .xgwx)을 바로 열지는 못하니 니모닉 형태(CSV, PDF, 텍스트)로 뽑아서 불러옵니다.
- 인덱스 수식, 파일 레지스터, 통신·위치결정 명령, 사용자 FB 정의 등은 무시하고 경고로 알려 줍니다.
